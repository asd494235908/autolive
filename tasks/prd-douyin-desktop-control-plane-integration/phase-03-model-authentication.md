# Phase 3：模型认证闭环

Parent PRD：[PRD：douyin-desktop 接入 autoLive 多产品控制面](../prd-douyin-desktop-control-plane-integration.md)
状态：Not Started
最后更新：2026-08-22

## 目标

删除“只有 URL、没有认证”的假租约语义，以本地 BYOK 作为 douyin-desktop 首版方案，并为经验证的委托短期凭证保留受限扩展。

## 主 PRD 上下文

- 目标：G-4
- 成功标准：SC-4
- 需求：FR-15～FR-20，NFR-3、NFR-4

## 发现门禁

- [ ] 盘点当前模型租约、Secret Store、账号测试、用量摘要和管理查询的全部密钥流向。
- [ ] 若考虑委托模式，查阅供应商官方文档并实测签发、范围、绑定、过期和撤销；宣传性描述不算证据。
- [ ] 检查桌面 OS 安全存储成熟库、Renderer/Main 边界和日志/错误报告脱敏路径。
- [ ] 定义 BYOK 与委托摘要的权威性差异和稳定错误码。

## 范围

### 包含

- `local_byok`、`delegated_short_term`、`unavailable` 三种契约模式。
- BYOK 零上传、非权威摘要和无租约语义。
- 可选一次性交付短期凭证、续租换新、释放/禁用/回收撤销。

### 不包含

- 不返回服务端长期共享 API Key，不建立模型正文代理。
- 不因接口名为 lease 就假设供应商具备短期委托能力。

## 实施清单

- [ ] OpenAPI 将认证模式和凭证交付定义为显式互斥结构；仅 URL 的旧结构进入兼容弃用路径。
- [ ] douyin-desktop 默认收到 BYOK 能力声明，不创建服务端模型租约。
- [ ] 定义 BYOK 摘要 `source=local_byok`、非权威标记和正文/秘密禁止字段。
- [ ] 委托模式必须绑定 lease/user/device/product，TTL 不超过租约且支持服务端撤销。
- [ ] 凭证只在创建/续租响应返回一次；列表、详情、数据库普通列、管理端、日志、trace 和审计禁止回显。
- [ ] 续租签发新凭证，释放/设备禁用/产品成员禁用/租约回收触发撤销；结果未知进入明确恢复状态。
- [ ] 未配置或供应商能力不合格时返回 `unavailable` 和可行动原因，不回退到长期共享 Key。
- [ ] 敏感信息扫描覆盖测试日志、HTTP fixture、错误报告、管理端构建产物和 trace exporter。

## 验证清单

- [ ] BYOK 从不出现在服务端请求、数据库、日志、审计、trace 或错误报告。
- [ ] 委托凭证范围外调用、过期、释放、禁用和撤销后均失败，旧凭证不会被续租重新激活。
- [ ] 同一租约凭证不能跨用户、设备或产品使用。
- [ ] 供应商不支持时不会返回成功 lease；客户端得到稳定可恢复提示。
- [ ] 用量摘要明确数据来源，不能伪装为供应商权威账单。

## 退出标准

- [ ] 任一启用模式都能真实完成认证，且不存在长期共享 Key 下发路径。
- [ ] 无合格委托供应商时，BYOK-only 是完整可发布状态而非临时假成功。

## 发现/决策

- 2026-08-22：用户确认 douyin-desktop 首版采用本地 BYOK；委托模式必须由供应商真实短期凭证能力解锁。
