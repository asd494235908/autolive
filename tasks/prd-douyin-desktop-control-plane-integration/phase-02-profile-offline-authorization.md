# Phase 2：Profile 与离线授权

Parent PRD：[PRD：douyin-desktop 接入 autoLive 多产品控制面](../prd-douyin-desktop-control-plane-integration.md)
状态：Not Started
最后更新：2026-08-22

## 目标

让服务端明确决定授权新鲜度和离线硬截止，客户端只能验证和执行，不能自行猜测或延长权益。

## 主 PRD 上下文

- 目标：G-3
- 成功标准：SC-3
- 需求：FR-9～FR-14，NFR-3～NFR-5

## 发现门禁

- [ ] 盘点 Profile 读取链、设备/用户状态、商业化订阅/席位依赖和客户端现有离线状态机。
- [ ] 确认签名算法、key id、轮换、吊销和旧公钥保留窗口，优先使用成熟 JOSE/COSE 类库。
- [ ] 定义服务端时间测试注入点，不在生产代码引入可绕过时钟。
- [ ] 明确断网硬截止后的允许保存/清理操作和禁止启动操作。

## 范围

### 包含

- Profile 授权字段、稳定原因码和签名离线授权。
- 6 小时建议复核、24 小时硬上限、权益修订和时钟回拨处理。
- 用户/产品成员/设备及后续订阅/席位失效的在线拒绝。

### 不包含

- 不承诺离线实时撤销，不把客户端时钟作为权益事实源。
- 不允许离线申请新模型凭证或下载新制品。

## 实施清单

- [ ] 在 OpenAPI 定义 Profile 字段、授权状态/原因枚举、签名载荷和兼容语义。
- [ ] 服务端统一计算 `server_time`、`authorization_checked_at`、`revalidate_at`、`offline_valid_until` 和 revision。
- [ ] 签名绑定 user/device/product/subscription/seat/revision/key id；默认 6h/24h，可缩短不可延长。
- [ ] 权益相关状态变化递增 revision，并使后续在线 Profile/敏感操作立即拒绝。
- [ ] 定义密钥轮换期间旧授权验证窗口，私钥只在服务端 Secret/KMS 边界。
- [ ] 客户端契约要求使用单调时钟和安全存储上次服务端时间；明显回拨进入 `offline_stale`。
- [ ] 网络恢复、前台恢复、模型凭证和制品下载前重新校验；硬截止后只允许本地保存和安全清理。
- [ ] React 管理详情显示授权状态/revision/最后校验和截止时间，不提供绕过截止的普通开关。

## 验证清单

- [ ] 可控时钟覆盖签发、6h 前后、24h 前后、提前缩短、时区和边界精度。
- [ ] 签名篡改、错误产品/设备、未知 key id、过期和回拨均 fail-closed。
- [ ] 在线禁用用户/成员/设备以及后续订阅/席位后立即拒绝，离线传播不超过 24h。
- [ ] 恢复网络能从 `offline_stale` 进入正确状态；失败不会清除用户本地数据。
- [ ] OpenAPI、Go 单元/集成、React 显示和跨客户端 fixture 通过。

## 退出标准

- [ ] 客户端无需猜测可用期限，服务端签名是唯一离线授权事实。
- [ ] 授权失败有稳定状态、原因和安全恢复路径。

## 发现/决策

- 2026-08-22：用户确认建议每 6 小时复核、签名离线授权硬上限 24 小时。
