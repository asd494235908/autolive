# Phase 10：客户端错误报告与反馈

Parent PRD：[PRD：服务端商业化与生产就绪](../prd-server-commercial-production-readiness.md)
状态：Not Started
最后更新：2026-08-22

## 目标

建立经过用户同意、客户端预脱敏、服务端再次脱敏的错误摘要接收与产品范围管理查询，并提供不扩张为工单平台的最小反馈状态流。

- 目标：G-9、G-10
- 成功标准：SC-11
- 需求：FR-36、FR-37、FR-42～FR-44，NFR-1、NFR-2、NFR-13、NFR-14
- 场景：场景 8

## 阶段发现门禁

- [ ] 盘点两个客户端的错误类型、现有日志/遥测、用户同意界面和本地脱敏能力；不直接复用旧 douyin 契约为事实源。
- [ ] 建立禁止字段和允许字段清单，覆盖 Token/Cookie、BYOK、短期凭证、Prompt/正文、本地路径、dump、截图和个人数据。
- [ ] 确认产品会话、产品成员/RBAC 已完成，匿名错误是否需要另立防滥用边界。
- [ ] 确认每类报告的批大小、字段长度、采样、速率、TTL、删除和管理员导出限制。

## 范围

### 包含

- 产品范围错误摘要、指纹、客户端版本/平台、有限错误码/堆栈摘要、时间和同意证据。
- 客户端预脱敏契约与 E2E 验证，以及本专项实施的服务端字段 allowlist/再次脱敏、幂等、指纹去重、采样、限流、TTL 和删除。
- 产品范围错误列表/详情与聚合趋势 React 页面。
- 产品范围反馈提交、列表、详情和 `open/in_progress/resolved/closed` 状态流。

### 不包含

- 不上传 crash dump、截图、附件、完整日志、本地绝对路径、模型正文或账号秘密。
- 不实现外部工单同步、邮件/站内通知、SLA 自动化或任意 SQL 导出。
- 不在本专项修改 Rust/Tauri 客户端；客户端预脱敏的实际接线由消费端任务实施，本阶段负责服务端契约、服务端二次脱敏和跨端验收门禁。

## 权限点

- `error_reports.read`、`error_reports.manage`
- `feedback.read`、`feedback.manage`

权限按产品角色绑定生效；`manage` 仅允许状态、受限备注和删除/保留例外，不允许查看已被拒绝或已脱敏的原值。

## 实施清单

- [ ] OpenAPI 定义严格 allowlist DTO、批大小/字段长度上限、稳定拒绝原因、幂等和 product 会话语义。
- [ ] 新增产品范围错误报告/事件/指纹和反馈表，设置 TTL 键、唯一约束、索引与引用；不保存拒绝字段原文。
- [ ] 定义客户端预脱敏契约和 fixture；服务端按字段类型再次规范化/脱敏，未知字段默认拒绝或丢弃并计数，不把原值写日志。
- [ ] 指纹只基于稳定、非秘密字段；去重和采样不能让单一产品耗尽全局容量。
- [ ] 接收 API 使用会话产品，不接受 body 任意切换；批量、压缩后大小、速率、超时和幂等均有界。
- [ ] 提供用户/管理员删除、TTL 清理和法务冻结例外；删除结果和例外可审计，不在审计中复制正文。
- [ ] 反馈文本进行长度、编码、危险 URL/HTML 和敏感字段校验；状态转换用显式状态机和并发版本。
- [ ] React 使用 Ant Design Table/Descriptions/Form/Tag 展示产品、版本、指纹、计数和状态；不提供原始 dump/完整日志下载。
- [ ] 增加每产品固定低基数接收量、拒绝量、采样量、存储量和处理时延指标，不使用报告/用户/设备 ID 标签。
- [ ] 同步隐私说明、产品/管理/数据库/保留与运维文档。

## 验证清单

- [ ] Token、Cookie、BYOK、短期凭证、Prompt、正文、路径、dump、截图和超限字段均不会入库/日志/审计/trace。
- [ ] 未同意、跨产品、无权限、批量过大、速率超限、未知字段和幂等冲突有稳定结果。
- [ ] 指纹去重、采样、TTL、用户删除、法务冻结和并发状态更新可恢复且可审计。
- [ ] 单一产品洪峰不会挤占其他产品全部容量，指标无高基数/秘密。
- [ ] Go/PostgreSQL/OpenAPI、React typecheck/test/build 和浏览器 403/空态/错误/删除冒烟通过。

## 退出标准

- [ ] 错误报告能支持定位趋势而不成为秘密、正文和本地文件上传通道。
- [ ] 反馈具备最小可用闭环，且没有提前扩张为工单/附件/通知平台。
