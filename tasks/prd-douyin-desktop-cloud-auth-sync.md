## 问题与目标

当前 douyin-desktop 的软件身份和用户资产仅存在一台电脑。用户更换电脑后，需要重复配置人设、回复策略、模型非秘密参数、知识库和长期记忆，也无法由 autoLive 统一执行软件账号与设备额度授权。

本期目标是让桌面端通过本地 sidecar 接入 autoLive：使用软件账号登录、自动绑定管理员预分配的设备授权，并在 `user + douyin_desktop` 空间内增量同步白名单资产。现有抖音登录、任务执行和本地安全门禁保持本机事实。

## 用户黄金路径

1. 用户在桌面端输入 autoLive 软件账号和密码。
2. sidecar 登录固定产品 `douyin_desktop`，绑定本机随机设备 ID，并确认 Profile 有效。
3. 首台电脑把本地白名单资产上传到空云空间。
4. 第二台获授权电脑登录同一账号，拉取知识、记忆和配置并重建本地派生索引。
5. 任一设备修改资产后按 revision 增量同步；同一项双向修改进入显式冲突，不静默覆盖。
6. 用户可退出软件账号；Refresh Token 从系统 Keyring 删除，本地抖音登录态和本地数据不被删除。

## 功能需求

- FR-1：桌面登录固定 `product=douyin_desktop`，密码不持久化，远端 Token 不进入 Renderer 或 SQLite。
- FR-2：复用 autoLive 现有 Access/Refresh Token 轮换、用户产品成员关系和账号绑定设备授权。
- FR-3：每次安装使用随机、非硬件指纹的稳定设备 ID；未授权、激活码撤销/过期、超额或禁用均 fail-closed。
- FR-4：服务端提供按用户、产品和设备认证隔离的增量拉取与 CAS 批量写入 API。
- FR-5：同步项只允许设计文档中的八种 kind 和固定 payload；秘密字段、未知字段、越界内容必须拒绝。
- FR-6：写入使用 mutation ID 幂等，重复相同请求返回原回执，相同 mutation 不同载荷拒绝。
- FR-7：本地 sidecar 提供会话状态、登录、退出、手动同步、冲突列表和冲突解决窄 API。
- FR-8：同步覆盖全局人设、全局回复策略、非秘密模型配置、知识来源/文档/分块/规则和长期记忆。
- FR-9：不上传抖音账号、Cookie、凭据引用、AI Key、任务/评论/发送事实、原文件二进制或派生索引。
- FR-10：云记忆在本地使用 `cloud_sync` 来源，不伪造不存在的反馈链；本地反馈记忆仍维持原外键完整性。
- FR-11：登录恢复、启动和手动操作可触发有界同步；单轮积压达到上限时提交已完整应用的 cursor、下一轮继续，失败不越过未应用项、不删本地数据、不显示假成功。
- FR-12：前端展示登录/授权/同步状态、最后成功时间和冲突处理入口，不直接请求远端。
- FR-13：正式 V1 业务接口要求最近 30 秒内的在线软件授权校验；登录、退出、会话状态和健康检查保持可达。
- FR-14：服务端校验模型、人设、策略的固定语义 ID 和知识父子/反向引用完整性；规则只能引用同文档且启用的分块，分块更新不得破坏既有规则，拒绝孤儿项、跨文档引用及带活动子项的父项删除。

## 非功能需求

- NFR-1：服务端从认证上下文取得 user/product/device，任何请求体都不能替换数据作用域。
- NFR-2：单批最多 100 项，单页拉取最多 200 项，桌面端单轮最多拉取 2000 项，单项最大 256 KiB；所有列表有界。
- NFR-3：数据库写入在短事务中分配单调 revision、更新事实并保存幂等回执，不在事务中调用外部服务。
- NFR-4：日志和错误只返回稳定类别，不包含密码、Token、同步正文或服务端原始错误。
- NFR-5：本地 SQLite 迁移可重复升级；云端迁移只新增，不修改历史迁移。
- NFR-6：不新增消息队列、WebSocket、Redis、对象存储或通用同步框架。

## 范围外与发布门禁

- 不修改 autoLive Rust/C# 桌面端、管理端页面或部署脚本；autoLive 仅修改服务端、迁移、OpenAPI 和服务端文档。
- 不在服务器构建；不切换分支或使用 worktree。
- 不提供离线授权、自助注册、激活码输入、SSO、账号找回、实时推送或跨用户共享。
- 不执行真实抖音写操作，不以自动化测试替代平台、许可、隐私或 Windows 发布验收。

## 风险

- 用户在两台设备同时修改同一事实会冲突；本期显式解决，不引入自动合并。
- 原始知识文件不上传，目标设备只能恢复规范化文本事实，不保证还原原文件版式。
- 本期在线授权要求 autoLive 可达；网络中断不会删除本地资产，但不能开始受保护的新操作。
- 当前用户资产是软件账号全局资产，不与某个本地抖音账号绑定；抖音账号继续保持本机隔离。
