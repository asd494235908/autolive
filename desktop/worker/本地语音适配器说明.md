# 本地 speech-to-speech 适配器

本目录提供 Hugging Face `speech-to-speech` 的本地 Worker 适配器，不是服务端，也不上传视频。

## 使用方式

先在本机安装依赖并启动 Hugging Face 的本地 Realtime 服务：

```bash
python3 -m pip install -r requirements.txt
speech-to-speech serve
```

然后把 `speech_to_speech_adapter.py` 配置到桌面端环境变量：

```bash
export AUTOLIVE_SPEECH_TO_SPEECH_WORKER="$PWD/desktop/worker/speech_to_speech_adapter.py"
export AUTOLIVE_SPEECH_TO_SPEECH_ENDPOINT="ws://127.0.0.1:8765/v1/realtime"
```

适配器支持 Rust Worker 契约的两种调用：

- `--capabilities-json <path>`：输出能力探测 JSON。
- `--input-json <context.json> --output-json <result.json>`：读取当前播放片段上下文，返回 `keep_original` 或带 WAV、SHA-256、时长、采样率、声道和同步偏移的 `rewrite` 结果。

源媒体片段由本地 `ffmpeg` 解码为 16 kHz、单声道 PCM 后通过 loopback WebSocket 发送。FFmpeg 只用于本地媒体解码，不承担 RTMP/OBS 推流。

适配器遇到依赖未安装、Realtime 服务不可用、媒体解码失败、超时或音频为空时，返回结构化 `keep_original`；Rust 继续执行候选门禁，失败不会暂停视频或创建新窗口。

Hugging Face 项目本身提供的是 VAD→STT→LLM→TTS 的低延迟 Realtime 管线，具体模型、中文效果、输出采样率和同语义改写质量必须用授权样片实测后再锁定配置。本适配器已经接入项目 Worker 契约，但不把“脚本可运行”当作真实无缝换轨验收。
