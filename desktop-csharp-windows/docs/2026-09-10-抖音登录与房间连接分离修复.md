# 抖音登录与房间连接分离修复

状态：代码、定向测试及本地构建完成；本轮真实重连与发送尚未验收。

## 功能边界

- 同一次应用运行内，已确认的抖音登录由现有 Windows Host 和受管 Python sidecar 持有；普通断开、换房、房间未开播和可识别的房间请求失败不注销登录。
- 同房间已经连接时，重复连接不得启动扫码、清空消息或重新发送；变更配置仍须先断开，再显式连接。
- 登录状态和房间连接状态分别表达。明确区分本次运行尚未登录、认证失效、辅助进程退出和本地通信异常，不能把所有失败归为登录失效。
- IPC 超时先核对进程与现有会话；无法确认安全状态时拒绝继续发送，必要时结束异常进程并保留真实原因，不能伪造已登录/已连接。
- 关闭查看窗口不注销登录；退出桌面账号、关闭应用及已确认认证失效仍释放凭据。凭据不跨重启保存。
- 不新增账号中心、自动重连框架、自动发送、凭据文件、Go API、数据库或模型调用。
