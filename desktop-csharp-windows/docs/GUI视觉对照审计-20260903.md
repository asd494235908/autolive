## v2 设计实施约束

- 首屏和下滑续页属于同一授权态主工作台，尺寸基准为 `1586×992`；第二张是中央参数区内部滚动后的连续内容，不新增路由、窗口、播放器或业务状态。
- 首屏中央显示视频周期参数的“自动生成 / 只读快照 / 已生效”状态、周期/轮次/GPU83/源素材和只读结果卡；不得继续用可拖动滑杆、可编辑数值框或仅禁用的结果控件。
- 下滑中央显示普通声音周期快照、预设池/周期范围规则、高级视觉、实时频谱、播放与设备状态、脱敏有界事件日志和说明卡。
- 用户可以编辑规则、范围、预设池、设备和输出配置，但不能直接改写系统生成的本周期视频/声音结果；重新生成是受控动作，不是结果编辑入口。
- `已生效` 只能由真实播放/输出运行时确认后投影，静态默认值、设计图夹具和模型校验都不能使用该状态。

## 证据限制

本次对照使用了仓库中的目标预览图、目标实际尺寸 `1586×992`、XAML 静态结构检查，以及临时 WPF 授权态渲染夹具生成的最新首屏图 [`gpautolive-authorized-layout.png`](../.tmp/wpf-capture/bin/Release/net10.0-windows10.0.19041.0/win-x64/gpautolive-authorized-layout.png) 和下滑图 [`gpautolive-authorized-scroll-layout.png`](../.tmp/wpf-capture/bin/Release/net10.0-windows10.0.19041.0/win-x64/gpautolive-authorized-scroll-layout.png)。夹具使用伪造的 `SourceMediaDto` 元数据和不存在的媒体路径，将 v2 目标图左侧六项缩略图及中央预览区裁剪为内存图，并在截图进程内注入设计稿示例快照值；仅验证窗口网格、控件主题、授权态投影、媒体池缩略图层级、中央预览比例和稳定文案，不代表真实 FFmpeg 首帧、真实生成周期或远程登录成功；当前会话仍未完成真实 WPF 窗口的 DPI/像素级采集。

要完成真正的 1:1 验收，仍需要：

1. 将壳启动时的快照生成迁移为真实周期所有者，按 v2 首屏继续补齐源素材/应用状态回显；结果值不得恢复为手动编辑控件。
2. 将规则/范围/预设池等有限编辑入口与系统生成结果拆成清晰的状态边界；重新生成、取消、失败和旧快照保留路径必须可验证。
3. 在 Windows 目标机以相同窗口尺寸、DPI 和授权/播放状态截取首屏与下滑页，再逐区进行像素、滚动、键盘和交互验收；当前仍不能标记为 1:1。
4. 使用 `src/GpAutoLive.App/Properties/launchSettings.json` 的远程测试配置启动，再以真实测试账号验证登录→自动激活→Refresh→退出；本轮未使用真实凭据，不能把远程地址可达等同于登录已通过。登录页仍需单独设计稿才能做 1:1 验收。
