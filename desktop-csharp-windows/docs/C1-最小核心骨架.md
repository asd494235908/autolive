# Phase C1：最小 WPF 壳与核心骨架

状态：已建立，媒体与 Windows 原生能力仍未接入。

## 项目边界

- `src/GpAutoLive.Contracts`：只包含跨进程/跨层的版本化 DTO、状态枚举和严格 JSON 选项，不引用 WPF、Windows 或媒体实现。
- `src/GpAutoLive.Core`：只包含不可变 `AppState` 快照，依赖方向为 `Core -> Contracts`。
- `src/GpAutoLive.Windows`：Windows 能力边界占位；C1 不执行原生调用、不启动子进程。
- `src/GpAutoLive.Media`：媒体运行时资源边界占位；C1 不启动 mpv、FFmpeg 或 sidecar。
- `src/GpAutoLive.App`：WPF 三栏壳、键盘入口、焦点可视样式、DPI manifest 和单实例互斥入口。
- `tests/GpAutoLive.Contracts.Tests`：验证 JSON 字段命名、枚举字符串和值边界。
- `tests/GpAutoLive.Core.Tests`：验证初始状态和 record 快照更新不会修改原状态。
- `tests/GpAutoLive.App.Tests`：验证空媒体池不会误进入播放态，以及停止操作会清理壳层进度。

组合根为 `GpAutoLive.Windows.slnx`。媒体、进程管理和 Windows 原生集成不在本次骨架内。

## 工程约束

- SDK 通过 `global.json` 固定为 `.NET 10.0.400`，本地副本位于 `.tools/dotnet`。
- 生产库目标为 `net10.0`，启用 nullable、分析器、确定性构建和 NuGet lock file。
- JSON 使用 `System.Text.Json`；属性名使用 `snake_case`，未知字段 fail-closed，枚举使用小写字符串。
- `AppState.SourceMediaPool` 使用 `ImmutableArray`，状态变更通过 record `with` 生成新快照。

## 验证

在 `desktop-csharp-windows/` 目录执行：

```powershell
.tools\dotnet\dotnet.exe restore GpAutoLive.Windows.slnx --locked-mode
.tools\dotnet\dotnet.exe build GpAutoLive.Windows.slnx -c Release --no-restore
.tools\dotnet\dotnet.exe test GpAutoLive.Windows.slnx -c Release --no-build --no-restore --verbosity minimal
```
