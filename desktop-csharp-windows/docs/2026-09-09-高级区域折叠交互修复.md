# 高级区域折叠交互修复

日期：2026-09-09。

## 范围与验收

用户反馈所有展开、收起入口无法操作。本轮覆盖 WPF 主窗口的固定话术、抖音弹幕卡片，以及已有的 RTMP 输出选项、插话文件池、抖音本地回复池三个高级区域。

验收要求：带折叠箭头的标题可以展开和再次收起，展开后的配置内容可见；键盘聚焦标题时，空格键由控件处理，不触发播放快捷键。固定话术和抖音弹幕卡片默认展开、收起后仍显示标题和状态徽标；三个高级区域默认收起。内部配置、登录与业务操作门禁继续由原有实现负责。

本轮不调整媒体、麦克风、推流、弹幕协议或配置持久化，不新增依赖。旧布局回归直接设置 `IsExpanded`，不能作为鼠标或键盘交互通过的证据。

## 原因与运行窗口核验

- 固定话术、抖音弹幕标题前的下拉箭头原为纯 `Path` 图形，父级只是 `StackPanel/Grid`，没有折叠交互。运行窗口点击固定话术箭头后内容不变，与代码一致。
- 三个高级区域使用真正的 WPF `Expander`。本轮在用户原有运行窗口中通过鼠标点击确认 RTMP 和抖音高级区域可展开、再次收起；插话文件池已展开并滚动看到目录、周期、音量与设备配置。旧程序并非所有折叠控件都失效。
- 播放快捷键的 `PreviewKeyDown` 抢先消费空格键，导致折叠标题获取焦点时不能由控件切换状态。
- 插话入口靠近滚动区底部时，展开内容仍可能在视口下方，需要继续滚动查看，不能把箭头状态变化等同于配置已出现在首屏。
