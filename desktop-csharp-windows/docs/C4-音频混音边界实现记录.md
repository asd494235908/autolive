# C4 音频混音边界实现记录

日期：2026-09-02  
状态：代码已接入·待真实候选、设备和音频时钟验收

## 已实现

- `src/GpAutoLive.Media/AudioPcmMixer.cs` 提供无状态、有界、调用方提供目标缓冲的交错 `float32` 混音入口。
- 支持普通媒体与插话 PCM 长度不同的情况，缺失一侧按静音处理；输入中的 `NaN/Infinity` 会收敛为静音，输出限制在 `[-1, 1]`。
- 增益统一以 `-120～24 dB` 校验；ducking 只作用于普通媒体，静音优先于增益，不创建临时 PCM 数组。
- `FinalPcmBus.TryPublishMixed` 使用预分配 scratch 缓冲后再向 PortAudio/RTMP 两个固定容量消费者发布，避免把音频正文放入无界队列。
- 该切片与 `AudioPriorityCoordinator` 的策略对应：麦克风/固定话术时低优先级层静音，插话文件时普通媒体 duck。

## 明确未实现

- 尚未提供 FFmpeg 普通声音候选 N/N+1 解码任务、插话文件递归池、交叉淡化、attack/release 包络或抢占后的实际 PCM 释放。
- SAPI 当前仍是独立 Windows 输出，尚未将其音量路由到该 PCM 混音器；真实静音/恢复需 Windows 声卡门禁。
- 尚未接入可听 PTS 主时钟、AEC/降噪/AGC/完整 VAD 或 RTMP 网络输出；PortAudio 设备健康观察与有界重开已在输出会话边界接入，但真实设备拔插仍待验收。

## 验证

`AudioPcmMixerTests` 覆盖 duck、固定话术静音、非有限值清理、输出限幅、输入边界和双消费者发布；当前全量 .NET 测试为 253 项通过。纯逻辑测试不替代 Windows 目标机真实声卡、长稳和音画同步验收。
