## 已实现的行为

| 链路 | 修复与验收边界 |
| --- | --- |
| FFmpeg PCM 解码 | CTS 在锁内摘除后释放；Stop 归类 Cancelled；Dispose 检查真实 Join，超时明确失败且可重试；reader 失败终止生产进程。释放前确认 Windows 进程句柄实际触发，不能把 `HasExited`/`WaitForExitAsync` 的早返回当作资源清理完成。 |
| WPF 关闭 | 在 OnClosing 持有异步退出任务，Dispatcher 保持运行；拒绝新命令，等待在途命令和观察者；失败保留窗口与 owner 供重试。已结束的后台异常被观察，不会让每次关闭永久卡在同一个失败 Task。 |
| mpv 退出 | 停止失败不丢弃 runtime、Process、Job；以 `WaitForExit(0)` 和有界真实句柄等待确认退出，未确认退出不报告 Dispose 成功。 |
| RTMP 起点与周期 | 复制本机未读有界 PCM 捕获首帧源锚点，保留 N+1；两消费者按相同候选边界切片。overlay 跟随各自基础轨，跨候选分段混音，远端 overlay 不单独推进时间轴。独立音频首次从相同起点解码，后续循环回零。 |
| RTMP 停止 | 视频 `q`、音频 EOF，AV 使用 `-shortest -shortest_buf_duration 0.1`；写入取得串行锁后复核会话，stderr 持续读取，确认进程和读取任务退出后才释放。快速退出/启动失败/自然退出使用同一受管清理边界。 |
| 暂停与 seek | 暂停停止旧发布，恢复重新捕获锚点；seek 同时重建声音，声音就绪后按可听 PTS 再校正视频。暂停中 seek 不开启 PortAudio，恢复时从新位置重建。 |
| 麦克风 | 启动/停止阈值形成迟滞，轻声保持及恢复、零挂起、稀疏观测过期均有回归；未 Join 的监视任务与 CTS 保留，故障已结束任务不会永久阻断收尾。 |
| 原生音频 | Input/Output 共用专用单在途操作 owner；快照读取受管缓存；异步 Pause/Resume/Stop；超时不并发重开、不提前卸载 DLL 或释放回调。确认 Close/Terminate 后才释放相应资源。 |
| 文件插话 | 取消与 CTS 摘除同锁；每块 PCM 选择当前候选总线，旧总线关闭竞态只对未写入的 Closed 结果重新定位一次。 |

双分支仍分别混音，overlay 没有源帧时间戳；远端插话开始时刻可能受消费滞后影响，不能宣传为与本机逐采样一致。非 1 倍速音画组合明确拒绝。本版本 WPF 当前声音自动参数保持 1 倍速，未引入动态视频变速框架。详见 [RTMP 时间轴记录](./2026-09-07-RTMP声音时间轴修复记录.md)。

加入固定 AV 缓冲边界后，`AV→video` 接收、解码和进程退出均为 0，服务端日志确认即时 `Stop publishing` 与注销/重新注册（`rtmp-av-video-final.log`、`zlm-av-video-final-server-redacted.log`）。服务端会给视频自动添加 8kHz 单声道静音 AAC；它不是旧 AV 的 48kHz 双声道 AAC，不能误写为服务端只有 H.264。该轮 AV 正常停止 657ms，但下一轮 750ms 预算仍发生强杀，因此进一步将正常退出预算重分配为 1.5 秒、总清理预算仍为 2 秒，并重复验证。`-shortest_buf_duration` 控制同步缓冲而非无输入超时；固定小缓冲的结束边界精度仍需按环境验收。[FFmpeg 官方说明](https://ffmpeg.org/ffmpeg.html#Advanced-options)

最终固定 1.5 秒正常退出预算的两轮中，视频停止 545/485ms、音频 22/30ms、AV 498/526ms，均正常退出；三轨道顺序、相同缓冲参数下的反向切换与源区段标记已分别验证。后续原生句柄确认补丁另由进程回归及最终全套覆盖，未重复网络实测。此前失败日志仅作为定位过程保留。只读 SSH 会话全部退出，未修改或重启服务器。

## 内存与资源观察

10 轮采样在输入、输出和总线显式 Dispose 后执行 GC。私有内存约 21.25～25.85 MiB；托管内存后半段约 4.4 MiB。句柄由 422 到 456，线程由 23 到 26。短测没有显示托管内存持续线性增长，但句柄/线程变化尚不能排除长期资源增长，不能写成“证明无泄漏”。最终未发现本轮遗留 ffmpeg、ffprobe、mpv、ReviewProbe 或 testhost 进程。

永久卡死的原生驱动不能在同进程安全强杀；预算返回失败后保留原操作与 DLL/回调所有权是必要边界。实体设备拔插/休眠、真人听感、目标显卡矩阵、RTMPS/鉴权和 30 分钟长稳本轮未执行。
