# Phase C2：WPF 登录门禁

状态：代码已接入·登录错误边界已加固·待真实控制面联调

## 已实现

- 冷启动会话恢复在登录门禁启用前完成；主窗口不再把恢复任务放到加载末尾后台执行，避免恢复结果覆盖用户刚完成的账号登录或设备授权。
- `LoginViewModel` 只维护账号、登录状态和短期密码输入；密码不会写入 INI、JSON、日志或 Credential Manager。
- 初始状态为 `SignedOut`，工作台和播放栏保持禁用并由登录门禁覆盖。
- 只有 `Activated` 才能进入工作台；`Authenticated` 仍等待服务端设备授权确认。
- `Offline` 只能从已授权会话进入，表示已进入工作台后的断网续播；冷启动不能用离线状态绕过登录或激活。
- `Disabled`、`ActivationRequired`、未授权 `Offline` 始终 fail-closed。
- 未配置控制面时仍只做本地输入/状态投影，明确提示配置要求，不创建 `HttpClient`；正式环境显式配置并通过 HTTPS 校验后，由 `ControlPlaneAuthCoordinator` 执行真实登录/自动激活/Refresh/Logout/心跳。测试联调使用 `AUTOLIVE_CONTROL_PLANE_ENV=test`，或本地开发使用 `AUTOLIVE_CONTROL_PLANE_ENV=development` 时，允许固定测试地址 `http://101.96.208.132:9090` 或 loopback HTTP；其他远程 HTTP 地址仍拒绝。
- 登录尝试、取消、刷新、退出和状态切换都会清理密码控件与 ViewModel 的内存副本。
- 登录/Refresh 的认证失败会执行状态机返回的删除凭据动作，避免失效 Refresh Token 继续留存；登录已成功后的设备激活失败属于授权边界，除明确 401/`UNAUTHENTICATED` 外保留账号会话与 Refresh Token、继续关闭工作台，并允许用户直接重试设备授权，不再要求重复输入密码。串行门等待阶段取消会返回受控的 `CONTROL_PLANE_CANCELLED` 结果，不再向 WPF 冒泡 `TaskCanceledException`。
- 登录门禁明确区分“账号登录失败”和“账号登录成功、设备授权失败”。设备授权失败展示稳定错误码与服务端 `request_id`（存在时），并提示点击“重试设备授权”；`DEVICE_LIMIT_EXCEEDED` 明确说明设备授权数量达到上限，401/`UNAUTHENTICATED` 明确要求重新登录。
- Credential Manager 异常、控制面客户端异常和用户取消分别映射到脱敏错误；WPF `LoginViewModel` 对控制面调用做最后异常收口，退出时发生未知客户端异常也会 fail-closed 清理本地会话。
- 启动恢复只读取当前 Windows 用户 Credential Manager 中的 Refresh Token；恢复响应仍必须完成设备激活。设备授权失败保持登录但不开放工作台，只有账号会话明确失效时才清理持久凭据。
- C# 是后续版本唯一桌面认证事实源；多设备模式下 C# 与 Rust 使用独立设备 ID。仅在 C# 设备 ID 缺失的首次迁移场景从固定 Rust 旧目标复制合法设备 ID，不迁移密码、Refresh Token 或待撤销 Token，也不覆盖已经建立的 C# 身份。
- 进入 `Activated` 后由单一后台调度器发送 30 秒心跳；调度器可取消、只保留一个任务，退出会等待该任务 Join，断网补发只保存一条不含 Token 的心跳请求。播放状态只上报服务端允许的 `idle/playing/paused/error`，`Ready/Stopped` 统一映射为 `idle`。每轮发送前检查本地授权和 Access Token 到期时间；Token 会在下一心跳周期前到期时先串行 Refresh 并重新确认设备授权，心跳首次返回 `401/UNAUTHENTICATED` 时也只 Refresh 并重试一次。
- 心跳的参数、冲突或普通业务错误只更新错误投影，不再删除 Refresh Token 或伪造退出；明确的设备禁用/撤销仍清理会话，其他 `403` 收回工作台但保留账号会话，只有 Refresh Token 被确认拒绝时才回到未登录并删除凭据。这些边界不改变服务端按设备额度支持的多设备登录。
- 远端 Logout 未确认时，本地会话立即清理；待撤销 Refresh Token 使用独立 C# Credential Manager 槽位有界保存，启动恢复前重试，不会恢复已退出的本地会话。
