# C7 发布启动关闭冒烟验证

`tools/smoke-csharp-windows-release.ps1` 是 C# Windows 候选包的最小进程级冒烟入口。它只验证发布目录中的 `GpAutoLive.exe` 是否能够使用仓库锁定的 `.tools/dotnet` 启动、暴露顶层窗口、收到 `CloseMainWindow()` 后在有界时间内退出，并确认 `GpAutoLive`、`mpv`、`ffmpeg`、`ffprobe` 没有残留。

脚本不会启动媒体、虚拟摄像头、抖音 sidecar 或网络功能；检测到同名进程已存在时会 fail-closed，不会触碰已有进程。输出为单个有界 JSON 对象，实际冒烟可用 `-OutputPath` 原子保存报告。

## 实际冒烟

在 `E:\aotlve` 执行：

```powershell
& .\desktop-csharp-windows\tools\smoke-csharp-windows-release.ps1 `
  -PackageRoot .\desktop-csharp-windows\artifacts\csharp-windows-controller-20260903-v83 `
  -OutputPath .\desktop-csharp-windows\artifacts\csharp-windows-smoke-v83.json
if ($LASTEXITCODE -ne 0) { throw "release smoke failed: $LASTEXITCODE" }
```

通过条件是 JSON 的 `status` 为 `passed`、`wait_for_input_idle` 为 `true`、`window_available` 为 `true`、`close_main_window` 为 `true`、`forced_kill` 为 `false`、`exit_code` 为 `0`、`residual_process_count` 为 `0`。

## 计划模式

`-PlanOnly` 或 `-WhatIf` 只校验候选 EXE 与 `.tools/dotnet\dotnet.exe`，输出启动计划，不启动进程、不写报告文件：

```powershell
& .\desktop-csharp-windows\tools\smoke-csharp-windows-release.ps1 `
  -PackageRoot .\desktop-csharp-windows\artifacts\csharp-windows-controller-20260903-v83 `
  -PlanOnly
```

该脚本与 C# 源码构建分离，使用现有发布候选进行验证；不修改 `desktop/` Rust/Tauri 参考目录。
