# 插话播放器与音轨优先级实施计划

> 当前版本范围声明（2026-08-19）：本版本不开发实时话术幻化。本文原计划中的实时变体、`realtime_variant` 基础音轨和 speech-to-speech 链路均为历史/后续版本内容；当前实施只保留普通源音轨、普通声音处理、插话 duck 和固定话术系统朗读。

> **For agentic workers:** 本计划由主线程拆分为两个不重叠写入范围并行执行；实现必须先写失败测试，再写生产代码。

**Goal:** 在桌面端最终效果窗口加入本地随机插话播放器，并统一固定话术替换、实时变体、原声和插话的优先级与回退行为。

**Architecture:** Rust/Tauri 负责音频文件夹规范化、音频文件扫描、配置校验和播放快照；最终效果窗口把当前基础音轨和插话音轨分成独立出口。当前基础音轨按 `processed_original > original` 解析；`realtime_variant` 仅为后续/历史兼容值，不属于本版本。固定话术是独立的系统语音朗读，不进入基础音轨枚举；插话永远是叠加层，插话开始时通过 duck 平滑降低当前基础音轨。首段插话按当前 UI 配置随机选择，后续每段完成后按调度器决定下一段。

**Tech Stack:** Rust std、现有 Tauri 2、React 18、Web Audio API、Ant Design、现有 FFmpeg/FFprobe 能力探测；不新增依赖，不接入 Go API，不在服务器构建。

## Global Constraints

- 不使用 Git worktree，直接在当前分支和工作区实现。
- 不把插话文件、目录路径或视频内容上传 Go 后端。
- 不把插话音频写入 `current_audio_source`，不得破坏实时变体候选状态机。
- 固定话术替换是最高优先级；固定话术生成/播放期间不启动新的插话。
- 插话仅实时叠加，不生成新的 MP4，不重新创建最终效果窗口。
- 暂停、停止、切换源视频、进入下一轮时必须取消或复位插话和闪避状态。
- 所有路径、目录、扩展名、数量、时间和增益参数必须在 Tauri/Rust 边界校验。
- 现有未提交改动属于用户；只修改本计划和任务明确的文件。
