# 当前话术人声克隆热替换实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有桌面端 MP4 播放流程中加入本地 CPU 人声提取、参考音色克隆和当前话术热替换，同时保持视频处理、普通声音处理、实时 speech-to-speech 和现有 MP4 选择行为不变。

**Architecture:** 新增独立的 `voice_clone` Rust 数据契约和 Worker 生命周期，Python Worker 负责 FFmpeg、Demucs、faster-whisper 和 XTTS-v2 的本地编排。Rust 以当前播放代际、源路径和操作 ID保护异步结果；React 复用现有 MP4 导入/播放状态，增加手动文本、最多 10 条本地预制文本和独立音频槽。

**Tech Stack:** Rust 2021、Tauri 2、React 18、TypeScript 5、Ant Design 5、Python 3.10+、FFmpeg/FFprobe、`demucs==4.1.0`、`faster-whisper==1.2.1`、`TTS==0.22.0`。

## Global Constraints

- 复用当前已有的“选择 MP4 → `probe_media` → `source_media`”链路，不新增文件选择器或视频队列。
- 固定文本替换使用独立 `VoiceCloneReplacementState` 和独立音频槽，不复用实时音频候选字段。
- 不调用或修改现有视频处理 Worker、视频缓存、视频处理开关和 `current_video_reference`。
- 不调用或修改现有普通声音处理参数、声音处理 Worker、声音处理开关和参数重置逻辑。
- 实时音频候选正在占用音频时，固定文本替换必须拒绝并保持原状态。
- 参考人声必须从原始源 MP4 提取，不得从视频或声音处理缓存提取。
- 首版固定 CPU/int8，不新增 NVIDIA/CUDA 安装、构建或运行路径。
- 视频画面继续播放；不创建新窗口、不生成 N 个 MP4、不修改原始 MP4。
- 用户文本最多 500 个 Unicode 字符；本地预制文字最多 10 条。
- 替换音频格式、路径、时长和完整 SHA-256 校验不通过时不得切换。
- 异步 Worker 必须有所有者、取消路径、超时、Join 和 staging 文件清理。
- 所有输入都视为不可信；路径必须规范化并限制在当前源文件或应用缓存边界内。
- 文本、完整本地路径、模型文件路径和临时 Worker JSON 不进入日志、Go API 或审计记录。
- 代码、模型依赖和构建均在本地开发机或 CI 完成，不把源码放到服务器构建。
- 本次新增行为必须先写失败测试，再写生产代码；每个任务独立验证并提交。

- [ ] **Step 3: Implement the Worker adapter**

Implement only these operations:

1. `capabilities()` imports `demucs`, `faster_whisper`, and `TTS` defensively, checks the configured FFmpeg/FFprobe paths, and reports `{available, status, provider, model, reason}` without throwing.
2. `prepare_source()` runs FFmpeg to extract the source audio, runs Demucs with an argument array and `--device cpu --two-stems=vocals`, normalizes the vocals reference, then runs `WhisperModel(model_size, device="cpu", compute_type="int8")` with `vad_filter=True` to return valid `VoiceCloneSegment` entries.
3. `replace_current()` loads XTTS-v2 with `TTS(model_name="tts_models/multilingual/multi-dataset/xtts_v2", gpu=False)`, calls `tts_to_file(..., speaker_wav=reference_audio, language="zh-cn")`, applies the exact duration rule from the spec, then uses FFmpeg `filter_complex` to concatenate `source[0,t0) + cloned + source[end,duration)` into one temporary playable audio file.
4. All subprocesses use argument arrays, `stdin=DEVNULL`, bounded output paths, and return structured failures. No shell interpolation, Go API request, or secret read is allowed.
5. Output includes operation ID, source SHA-256, replacement SHA-256, `replace_at_ms`, `resume_at_ms`, total duration, sample rate, channel count, model and status.

Use `requirements-voice-clone.txt` with exactly:

```text

faster-whisper==1.2.1
TTS==0.22.0
```
