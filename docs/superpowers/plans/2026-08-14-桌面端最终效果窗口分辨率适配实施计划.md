# 桌面端最终效果窗口分辨率适配实施计划

> 当前版本范围声明（2026-08-19）：本版本不开发实时话术幻化。本文提到的音频候选/音频逻辑仅作历史兼容边界说明；当前窗口适配验收不包含 speech-to-speech、实时话术候选或实时换轨。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `final-effect` 播放窗口根据当前视频的宽高适配显示器可用工作区；正常视频按原始尺寸显示，超出工作区时等比缩小，切换视频时复用同一个窗口且不影响主窗口和其他窗口。

**Architecture:** Rust/Tauri 负责读取 `final-effect` 所在显示器的工作区、计算带现有播放器 UI 预留空间的目标逻辑尺寸并调整窗口；纯尺寸计算独立为可测试模块。React 只从播放快照读取视频元数据，在尺寸或视频引用变化时调用受限 IPC，并用 ref 去重。视频元素使用 `contain`/自动高度保证完整显示，不改变播放状态机和音频逻辑。

**Tech Stack:** Rust 2021、Tauri 2、`tauri-runtime` DPI 类型、React 18、TypeScript、Node 内置测试、现有 pnpm/Vite 工具链。

- 所有尺寸输入在 Rust 边界校验；窗口尺寸失败不阻塞视频播放，不关闭窗口，不清空媒体源。
- 交付前检查本次改动产生的未使用导入、类型、导出、依赖和调试输出。
