# 本地媒体任务纵切片实施计划

> 文档状态：已废止（2026-08-13）。本文件是早期媒体任务方案的历史审计记录，不属于当前产品实施依据。当前产品只做单视频、单窗口循环播放和三个独立处理开关，不创建媒体任务或离线版本。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Current scope:** 当前首版不创建变体任务；本计划属于已废止的离线 N 版历史方案，当前播放器只维护单源循环和实时音频换轨。

**Goal:** 记录早期离线 N 版桌面端变体任务的 `prepare` 阶段设计和控制面上报边界，仅供审计，不再推进实现。

**Architecture:** Rust 核心在应用数据目录的任务子目录中执行只读源 MP4 校验、完整 SHA-256 和准备清单生成；Tauri 只负责安全路径边界和 IPC。React 桌面端调用现有 Go 的 start/events/cancel 接口，prepare 成功或失败后按稳定事件 ID 上报，任务不会提前完成。

**Tech Stack:** Rust 2021、Tauri 2、Serde/serde_json、现有 `mp4`/`sha2`/`sysinfo`、React + TypeScript + Ant Design、Go 现有控制面和 OpenAPI。

## Global Constraints

- 不接 RTMP/OBS，不实现平台推流，不上传本地视频。
- FFmpeg 只保留为后续本地媒体引擎候选；本切片不依赖其安装，也不伪造重编码成功。
- 源 MP4 只读；阶段产物不能静默覆盖已验收文件。
- MP4 使用整个文件字节流 SHA-256；JSON 等非 MP4 产物使用完整文件字节流 SHA-256。
- Rust、React、Go 使用成熟库/官方 SDK，不重新实现编解码、哈希或 UI 组件。
- React 继续使用 Ant Design，不修改 `.ant-*` 样式。
- 所有新行为先写失败测试，再写最小实现；每个阶段必须处理成功、失败、取消和幂等路径。
- 文件名和文档使用中文；代码标识符遵循既有英文 API 命名。
