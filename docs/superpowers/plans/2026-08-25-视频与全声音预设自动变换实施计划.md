# 视频与全声音预设自动变换实施计划

> 日期：2026-08-25  
> 状态：核心实现与契约同步完成；待本地全量门禁及感知验收  
> 适用范围：React/Tauri 桌面客户端、本地 Rust 媒体处理链、随机插话  
> 不包含：实时话术幻化、speech-to-speech、VAD、ASR、LLM、TTS、水平翻转、垂直翻转

> 覆盖声明（2026-08-28）：本方案只保留已确认的参数字段、声音预设和独立周期事实。视频执行、回退和验收以 [`mpv/libplacebo 实时 GPU 主链实施方案`](./2026-08-28-mpv-libplacebo实时GPU主链实施方案.md) 为准；83 项逐字段证据完成前不得宣称 GPU83 已生效。

## 1. 目标

1. 视频处理只有一种自动模式。开启后，除水平/垂直翻转外，所有具有真实处理路径的视频和高级视觉参数自动小幅变化；输出像素实际改变，但以人眼难以察觉为目标。
2. 画中画、挂件、随机图形等效果保持启用，以非零的小透明度、小尺寸、短时长和低强度进入真实 FFmpeg 输出。
3. 将“音高、变速与共振峰”“特征、信噪比与空间混合”从高级声音抽屉移动到主页声音参数列，不保留重复入口。
4. 22 套声音预设显式覆盖全部 35 个可写声音效果字段。第 1–20 套低感知，第 21、22 套明显可听且只在用户显式选择时参与。
5. 普通声音与随机插话共用同一份 22 套预设定义和参数完整性规则。
6. 目标信噪比默认显示“自动”；用户未选择环境声时，普通声音和随机插话统一使用程序内置的极低电平本地环境底噪。

## 2. 强制边界

### 2.1 视频

- 只保留一个视频处理开关和一种自动低感知行为，不增加模式选择器。
- `horizontal_flip_enabled`、`vertical_flip_enabled` 本次不参与自动变化，也不删除现有兼容字段。
- 其余参数必须归入以下一种状态：
  - 独立连续参数：本轮产生非零、最小有效变化；
  - 开关加从属强度：开关保持启用，从属强度为非零低值；
  - 从属调度参数：随其所属效果进入快照并影响滤镜计划；
  - 只读/源素材值：只展示，不伪装为自动变化。
- 视频周期必须产生完整的 `VideoEffectParams + AdvancedEffectParams` 快照，不能只改变 CSS 预览字段。
- FFmpeg 必须解码、处理并重新编码；`applied_fields` 是“真实参加变换”的证据。

### 2.2 声音

Rust `AudioEffectParams` 共 37 个字段：

- `random_change_period_ms` 是全局调度结果，不属于单套声音预设；每轮仍写入最终 Rust 快照。
- `current_formant_hz` 是只读诊断值，不属于预设输入。
- 其余 35 个字段全部显式存在于每套声音预设，不允许通过缺字段静默继承默认值。

35 个预设字段包括：

- 模式与音色：自然动态模式、音色库 ID；
- 增益与均衡：输入增益、输出增益、响度、低/中/高频 EQ、滤波 Q；
- 音高与变速：音高、播放速度、共振峰、颤音频率、颤音深度；
- 频谱与特征：频谱微扰、相位扰动、MFCC 偏移、MFCC 维度、频谱盲区；
- 信噪比与噪声：SNR 浮动、目标 SNR、环境噪声比例、环境噪声电平、降噪；
- 空间与混合：混响、干湿比、环境声混合；
- 时间与编码：淡入、淡出、采样率、输出码率；
- 高频扰动：开关、间隔、强度、目标电平。

### 2.3 多轨与总线

- 每条虚拟轨都由完整预设生成，不再把未列入必要共享集合的字段覆盖回默认值。
- 分轨字段可按轨道变化；混音后 DSP 和共同时间轴字段由本轮主预设统一应用。
- 必须共享的字段包括：播放速度、输出采样率、输出码率，以及当前 Rust 混音后总线执行的音高、共振峰、MFCC、SNR、环境声参数。
- “共享”不等于“不参加”：这些字段仍由本轮主预设取值，并在混音后的真实总线执行。

## 3. 视频自动低感知方案

### 3.1 参数快照

视频周期样本同时包含 `video` 与 `advanced`。随机值先按正式参数范围生成，再由 Rust 信任边界二次校验；水平/垂直翻转保留兼容值但不进入自动池。

### 3.2 画中画、挂件和随机图形

- `picture_in_picture_enabled=true`；
- `random_graphic_enabled=true`；
- 挂件/抽象图形数量至少为 1；
- 透明度、大小、位置、旋转、抖动、切片时长和触发间隔使用非零低值；
- 已新增正式字段 `picture_in_picture_opacity_percent`，并同步 Rust/TypeScript 模型、默认值、校验、UI、FFmpeg 和文档；
- FFmpeg 对画中画支路先设置透明度，再执行 overlay，不能用不透明小窗冒充低感知效果。

### 3.3 调度与资源

- 播放开始立即生成首份快照；后续按视频周期准备下一份。
- 当前转码不抢停；并发请求只保留最新待执行快照。
- 新输出准备成功后在同一最终效果窗口中切换。
- 失败时沿用上一份有效输出并显示错误，不切到空白或未完成文件。

## 4. 声音预设方案

### 4.1 单一事实源

将 22 套预设放到独立模块，普通声音、随机插话、预设详情和测试全部引用该模块。不得在 App、插话或 Rust 中复制第二份预设表。

### 4.2 第 1–20 套

- 每套显式提供全部 35 个字段；
- 连续效果使用非中性低值；
- `snr_target_db=null`，表示自动读取源基线；
- SNR 浮动、MFCC、频谱盲区、干湿比和环境声混合均为真实有效的低值；
- 自然动态、音色库和高频扰动实际参与；
- 不以“每项单独很小”为由忽略叠加结果，最终以整套输出的客观指标和人工试听校准。

### 4.3 第 21、22 套

- 两套同样包含全部 35 个字段；
- 第 21 套突出增益、EQ、混响、环境声和空间混合；
- 第 22 套突出音高、速度、共振峰、颤音、MFCC、SNR 和音色；
- 两套均可显式勾选或固定选择，但不进入普通声音或随机插话的默认随机池。

### 4.4 全局周期

- 声音周期独立保存最小值和最大值，默认 8–15 秒，硬范围 1–60 秒；
- 每轮抽取一个实际周期并写入 `random_change_period_ms`；
- 多轨共享同一周期；
- 自然动态模式使用同一周期驱动缓慢响度包络。

## 5. 随机插话

### 5.1 复用预设

- 随机插话和普通声音共用完整 22 套预设；
- 默认随机池为第 1–20 套；第 21、22 套只在用户显式选择后参与；
- 删除 `allowP21` 等场景特例，统一由“是否显式选择”决定。

### 5.2 抽样方式

- 固定预设：每次使用指定完整预设；
- 每次插话重新随机：每段开始前抽样；
- 按周期更新：周期到期只影响下一段插话，不重启当前插话；
- 多轨最多 4 条，遵守第 2.3 节的分轨/总线边界。

### 5.3 输出路径

- PortAudio：继续使用 FFmpeg/PCM 流式插话处理；
- WebView 回退：为所选插话文件生成短期处理音频缓存后播放；处理失败时明确回退原声，不影响主音轨；
- 两条路径使用同一预设快照、同一环境声解析结果和同一参数校验。
- 当前段自然结束后删除对应短期缓存；停止、切换素材、出口切换或窗口卸载时先使 generation 失效，再取消并有界 Join 缓存生成/处理任务、删除缓存并恢复 duck；应用启动时清理上次异常退出遗留且已过期的插话缓存。
- 短期缓存只属于当前插话代际，不进入用户媒体库，不跨配置或媒体代际复用，不按 22 套预设预生成常驻文件。

## 6. 内置环境底噪

- 随桌面程序打包一个可循环、极低电平的本地音频素材；不联网、不下载、不上传服务器；
- 用户素材优先，没有用户素材时使用内置素材；
- 普通声音和随机插话调用同一个环境声解析入口；
- 两种来源都作为真实 FFmpeg 第二音频输入；
- 资源不可读或解码失败时保持原声并报告可恢复错误。

## 7. UI 迁移

主页声音参数列新增独立组件，承载：

- 音高、播放速度、共振峰；
- 自然动态模式、音色库 ID；
- MFCC 偏移/维度、SNR 浮动、频谱盲区；
- 干湿比、环境声混合、目标 SNR；
- 环境声素材与“用户素材/内置底噪”来源状态。

高级声音抽屉删除上述重复入口，保留 PortAudio、多轨与预设、声音周期、参数状态和缓存管理。目标 SNR 为 `null` 时必须可见显示“自动”。控件使用 Ant Design 公共能力，保留可见标签、键盘焦点、错误反馈和窄窗口单列布局，不覆盖 `.ant-*` 内部样式。

## 8. 模块与文件职责

- `audio-value-presets.ts`：22 套完整预设、字段清单、选择规则；
- `runtime-parameter-scheduler.ts`：周期与队列，不继续承载大段预设常量；
- `video-parameter-randomizer.ts`：完整视频/高级视觉低感知快照；
- `media-parameter-panels/AudioParameterControls.tsx`：主页声音输入控件；
- `media_effect_params.rs`：唯一 Rust 参数模型、默认值和校验；
- `media_video_effects.rs`：视频字段到 FFmpeg 的真实映射；
- 环境声资源解析使用独立、职责单一的 Rust 模块；
- `App.tsx` 只负责组合组件、调度和 IPC，不复制预设或媒体算法。

如现有公共边界已经足够，优先扩展现有模块，不为目录整洁额外制造无调用方抽象。

## 9. 多子代理开发与主线程等待验收

### 9.1 文件所有权

每个子代理获得互斥的文件范围；共享工作区中禁止两个子代理同时修改同一文件，不使用 Git worktree。

### 9.2 开发波次

第一波并行：

1. 声音预设与调度核心：完整 35 字段、22 套值、选择规则和单元测试；
2. 视频模型与随机器：完整快照、画中画透明度、FFmpeg 映射和 Rust/TS 测试；
3. 环境声与随机插话核心：内置素材解析、PortAudio/WebView 处理边界和测试。

第二波在第一波验收后并行：

1. 主页声音参数组件与响应式样式；
2. App 视频周期集成和真实渲染队列；
3. App 随机插话、普通声音和 22 套预设集成。

### 9.3 实施结果与剩余门禁

- 已完成视频单一自动低感知参数模型、完整 `video + advanced` 快照、翻转排除、PIP 透明度和真实 FFmpeg 字段映射；PIP、挂件、随机图形及其从属值保持启用且非零。
- 已完成 22 套精确 35 字段声音预设、`p01–p20` 默认池、`p21/p22` 显式选择、全局周期与预设分离、目标 SNR 自动，以及普通声音/随机插话共享预设事实源。
- 已完成用户环境声优先、内置极低电平底噪兜底的统一解析边界，以及 PortAudio 流式插话、WebView 短期处理缓存、明确原声回退与缓存清理生命周期。
- 已完成主页两个声音参数编辑区迁移，高级声音抽屉不保留重复入口；参数卡、诊断和周期状态继续只读。
- 自动化测试证明字段完整性、范围、选择规则、滤镜计划和错误/清理分支；低感知目标仍须用真实素材执行 SSIM/PSNR、人工观察、人工试听和 Windows 长时间双出口验证，未完成这些门禁前不宣称所有素材上绝对无感。

### 9.4 主线程等待方式

1. 主线程分配任务后进入等待，不并发修改子代理所有的文件；
2. 子代理完成后提交改动摘要、实际命令、结果和风险；
3. 主线程读取完整 diff，以代码总监视角检查字段覆盖、执行路径、错误处理、资源释放、重复代码和文档一致性；
4. 验收不通过时向原子代理发送具体整改项，并再次等待；除非用户取消或代理失控，不主动中止子代理；
5. 单项验收通过后才开放第二波依赖任务；
6. 所有子代理结束后，主线程统一处理跨模块集成、冲突和少量必要修复；
7. 主线程执行全量本地验证，未通过则按问题所有权退回相应子代理修复并继续等待；
8. 只有代码、测试、文档和本地构建全部达到验收条件后才向用户交付。

## 10. 验收条件

### 10.1 视频

- 水平、垂直翻转未进入自动池；
- 其余正式字段均被分类并有测试证明其真实执行或合法从属关系；
- 画中画、挂件、随机图形保持启用且强度非零；
- 每轮完整快照同时更新 `video` 与 `advanced`；
- 输出帧哈希与源帧不同；使用 SSIM、PSNR 和人工观察校准低感知范围；
- 参数切换不重建最终效果窗口。

### 10.2 声音与插话

- 22 套预设逐套精确包含 35 个效果字段；
- 第 1–20 套为默认随机池，第 21、22 套只显式参与；
- 普通声音和随机插话引用同一预设事实源；
- 单轨、多轨和混音后总线字段均有真实执行证据；
- 目标 SNR 默认显示自动；
- 无用户环境声时，内置素材作为真实第二输入；
- PortAudio 和 WebView 插话均有处理或明确原声回退状态；
- 周期到期不重启正在播放的插话。

### 10.3 工程验证

- 前端格式/测试/类型检查/本地构建通过；
- Rust 格式、相关测试、`cargo check` 和本地构建检查通过；
- 不在服务器构建，不使用 worktree；
- 本次暴露或产生的未使用代码、导入、类型、资源和调试日志已删除；
- 产品需求、桌面架构、媒体参数唯一契约和长任务计划与实现保持一致。
