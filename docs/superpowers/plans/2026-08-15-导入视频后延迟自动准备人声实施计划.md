# 导入视频后延迟自动准备人声实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在最终效果窗口成功打开后延迟 4 秒启动现有自动人声准备流程，同时保留取消能力且不引入哈希缓存。

**Architecture:** 在现有 `desktop/ui/src/启动调度.ts` 增加可取消的 AbortSignal 延迟辅助函数。`DesktopApp` 的导入流程只在最终效果窗口真正打开成功后启动自动准备；自动准备函数先等待 4 秒，随后沿用当前哈希轮询和 `prepareVoiceCloneSource({ automatic: true })` 流程。

**Tech Stack:** React 18、TypeScript、Tauri 2 IPC、Node `node:test`、pnpm。

## Global Constraints

- 自动准备必须保留，延迟从最终效果窗口打开成功开始计算。
- 延迟固定为 4 秒，不增加哈希缓存或文件指纹缓存。
- 延迟、哈希等待和 XTTS 准备必须可被切换视频、组件卸载或取消操作终止。
- 不修改 Rust 媒体探测、哈希算法、XTTS Worker、视频循环和固定话术播放逻辑。
- 直接在当前分支和工作区开发，不创建 Git worktree。

### Task 2: 实现可取消延迟并接入导入流程

**Files:**

**Interfaces:**

- Produces: `waitForAbortableDelay(signal, delayMs): Promise<boolean>` and a 4 秒延迟的自动准备入口。

- [ ] **Step 1: Implement the minimal scheduler helper**

在 `desktop/ui/src/启动调度.ts` 增加：

```ts
export function waitForAbortableDelay(signal: AbortSignal, delayMs: number): Promise<boolean> {
  if (signal.aborted) return Promise.resolve(false);
  return new Promise((resolve) => {
    let timer: ReturnType<typeof globalThis.setTimeout> | null = null;
    const finish = (completed: boolean) => {
      if (timer !== null) globalThis.clearTimeout(timer);
      signal.removeEventListener('abort', onAbort);
      resolve(completed);
    };
    const onAbort = () => finish(false);
    signal.addEventListener('abort', onAbort, { once: true });
    timer = globalThis.setTimeout(() => finish(true), Math.max(0, delayMs));
    if (signal.aborted) onAbort();
  });
}
```

- [ ] **Step 2: 接入 4 秒延迟并只在窗口打开成功后启动**

在 `App.tsx` 中：

```ts
const VOICE_CLONE_AUTO_PREPARE_DELAY_MS = 4_000;
```

让 `openFinalEffectWindowFromHome` 返回 `Promise<boolean>`：成功返回 `true`，异常提示后返回 `false`。导入流程使用：

```ts

```

在 `prepareVoiceCloneAfterImport` 创建 controller 后先执行：

```ts

  controller.signal,
  VOICE_CLONE_AUTO_PREPARE_DELAY_MS,

if (!delayCompleted) return;
```
