# 语音模型下载与打包 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让固定话术 Worker 在开发版明确显示模型下载/准备阶段，并在正式 Tauri 包构建时预下载、校验和内置 Demucs、Whisper、XTTS-v2 模型。

**Architecture:** Worker 通过原子 JSON 进度文件报告模型检查、下载、人声分离和转写阶段；Rust 线程读取进度并写入播放快照，React 以现有 500ms 快照轮询显示阶段。构建脚本把隔离缓存中的三套模型复制到 Tauri resources，Rust 通过资源目录环境变量让 Worker 离线读取。

**Tech Stack:** Python 3.11、Demucs 4.1.0、faster-whisper 1.2.1、TTS 0.22.0、Rust/Tauri 2、React/TypeScript、Node.js 构建脚本。

## Global Constraints

- 首版 CPU-only，不加入 NVIDIA/CUDA。
- 不改变 MP4 选择、视频处理、普通声音处理、实时音频幻化和最终效果窗口。
- 模型权重不提交 Git；构建阶段下载失败必须使构建失败。
- 开发版可使用本地模型缓存；正式包优先使用 `resource_dir()/voice-models`，模型资源缺失时明确不可用且不静默联网。
- 所有 Worker 外部进程必须支持取消、超时、进程组回收和 stderr 持续排空。
- 使用 TDD：每个行为先补失败测试，再写最小实现。
- 保留工作区中与本任务无关的用户修改，不回滚、不覆盖。
