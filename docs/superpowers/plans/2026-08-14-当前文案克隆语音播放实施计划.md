# 当前文案克隆语音播放实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 导入视频后自动准备参考人声；用户点击时只播放当前文案的克隆声音，播放期间静音原音轨，克隆声音结束后恢复原音轨；视频循环不自动触发文案播放。

**Architecture:** 在现有固定话术链路旁新增“当前文案独立音频片段”路径。Rust 负责源/文案身份、缓存、异步任务和播放状态；Python Worker 只负责单条文本 TTS；React 负责媒体元素同步和临时静音。旧的局部替换接口保留兼容，但新按钮不再调用它。

**Tech Stack:** Rust/Tauri、React/TypeScript、Python、Demucs、faster-whisper、Coqui XTTS-v2、FFmpeg/FFprobe、现有常驻 JSON Worker 协议。

## Global Constraints

- 只处理当前文本框中的一条文案；不得生成或播放文案队列。
- 视频循环不自动开始、重播、截断或重置克隆音频；没有新的用户点击时继续原音轨。
- 克隆音频播放期间原音轨必须静音；克隆音频自然结束、取消、停止或失败时恢复原音轨。
- 同一视频/参考人声/文案/模型参数命中缓存，不重复提取人声或加载模型。
- 不生成 MP4、不上传视频或完整音频、不引入 NVIDIA 专用实现、不影响其他媒体功能。
- 新异步结果必须校验 `playback_generation`、源 SHA、参考 SHA、文案 SHA 和 operation ID；正常 `loop_index` 变化不能使正在播放的克隆音频失效。
- 所有改动直接在当前工作区完成，不创建 worktree；只修改本功能相关文件，不清理用户已有无关改动。

详尽需求、发现记录和阶段检查清单见 [PRD](../../../tasks/prd-voice-clone-current-playback.md)。
