# 主页播放控制与纯画面播放器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将独立播放器的原生控制迁移到主页，让播放器窗口正常状态只显示视频画面，同时保持现有单窗口循环和窗口尺寸适配。

**Architecture:** `FinalEffectWindow` 继续拥有真实 HTML media elements，但移除 `controls`，通过已有 `autolive-playback-ui-v1` 通道上报媒体状态并接收主页控制意图。`DesktopApp` 拥有主页控件状态，Rust `PlaybackSnapshot` 仍是业务播放状态事实源；进度、音量和画中画属于播放器元素的界面状态，不新增 Rust 状态。

**Tech Stack:** React 18、TypeScript、Ant Design 5 `Slider`、Tauri 2、浏览器原生 `BroadcastChannel`/Picture-in-Picture API、Node `node:test`。

## Global Constraints

- 不使用 Git worktree；直接在当前分支和工作区开发。
- 不覆盖或回滚已有未提交的服务端、窗口适配和桌面端改动。
- 不新增依赖；复用项目已有 Ant Design、BroadcastChannel 和媒体 API。
- 弹出窗口正常播放时只渲染视频画面和隐藏音频元素；错误/无源状态可显示必要提示。
- 所有跨窗口消息必须版本化、字段校验，非法消息直接忽略。
- 本地构建和验证，不在服务器构建；交付前删除本次改动暴露的未使用导入、类型和状态。

```ts
if (action === 'seek') {
  video.currentTime = clampMediaTime(current_time, video.duration);
  if (audio) audio.currentTime = Math.max(0, video.currentTime - (snapshotRef.current?.current_audio_start_at_ms ?? 0) / 1000);
}
if (action === 'set-volume') {
  const volume = clampVolume(message.volume);
  video.volume = volume;
  if (audio) audio.volume = volume;
}
if (action === 'toggle-muted') setUserMuted((muted) => !muted);
if (action === 'picture-in-picture') {
  if (document.pictureInPictureElement === video) await document.exitPictureInPicture();
  else await video.requestPictureInPicture();
}
```

<Space direction="vertical" style={{ width: '100%' }}>
  <Typography.Text>播放进度 {formatMediaTime(mediaState?.current_time ?? 0)} / {formatMediaTime(mediaState?.duration ?? 0)}</Typography.Text>
  <Slider
    min={0}
    max={Math.max(mediaState?.duration ?? 0, 1)}
    value={Math.min(mediaState?.current_time ?? 0, Math.max(mediaState?.duration ?? 0, 1))}
    onChange={(value) => typeof value === 'number' && postPlaybackMediaControl({ version: 1, type: 'playback-media-control', action: 'seek', current_time: value })}
