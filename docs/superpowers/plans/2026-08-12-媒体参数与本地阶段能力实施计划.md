# 媒体参数与本地阶段能力实施计划

> 文档状态：已废止（2026-08-13）。本文件中的媒体任务阶段计划不属于当前产品实施依据；当前只实施单源循环、视频处理开关、声音处理开关和实时话术幻化开关。

## 当前范围

当前首版只需要参数契约、三个独立开关和单源循环预览；实时音频幻化只替换当前基础音轨，普通声音处理作用于最终当前音轨。真实 N 版生成和阶段 Worker 已废止，仅作历史审计。

## 已完成

1. 在 Rust 新增可序列化媒体研究参数模型。
2. 为音频、视频、固定视觉频段、挂件和切片参数增加默认值与范围校验。
3. 为阶段状态增加串行顺序、失败重试和终态不可覆盖规则。
4. 增加本地阶段能力查询，并在 Tauri 桌面端显示真实能力。
5. 增加 Ant Design 参数面板，区分配置值、只读测量值、SHA-256 和研究开关。

## 后续

1. 将参数面板 DTO 映射到 Rust `LocalResearchParams`，通过 IPC 做完整校验。
2. 将已验证参数写入任务配置快照和阶段事件。
3. 在有真实媒体依赖时逐项接入 FFmpeg 滤镜、音频分析库和成熟音频处理适配器。
4. 接入真实 ASR/模型代理/TTS 配置后，再实现 `transcribe → rewrite → tts` Worker。
5. 为每个阶段补充输入/输出哈希、超时、取消、重试和可恢复产物测试。

## 验收边界

本计划完成不代表完整变体流水线完成，也不代表研究参数已经改变媒体内容；只代表契约、能力状态和 UI 展示已具备可验证基础。
