# 桌面端主页与独立播放器窗口实施计划

## 功能边界

- 保留固定 label 为 `final-effect` 的单独播放窗口。
- 主窗口承载所有控制、状态、参数、波形、频谱和研究信息。
- 不生成 N 个视频，不引入 RTMP/OBS，不改变 Go 服务端。
- 播放循环必须是本地优先，状态同步失败不能阻塞媒体播放。
- 自动参数变化只作用于本地连续预览；未接入的高级 DSP 参数不伪造为已生效。

## 执行步骤

1. 增加纯逻辑测试，覆盖参数周期、范围裁剪、关闭开关和循环结束防重复。
2. 将 Ant Design `ConfigProvider` 配置为高对比度深色主题，并整理主窗口信息区。
3. 把播放控制、状态、波形/频谱通信和自动参数状态放入主窗口。
4. 收缩 `FinalEffectWindow` 为播放器窗口，通过 `BroadcastChannel` 接收运行时参数并发送诊断采样。
5. 修复 `onEnded`、`timeupdate` 和换源时的循环兜底，保证单窗口连续播放。
6. 检查 Tauri 单实例窗口命令和 IPC 调用方，清理失效导入、类型和重复逻辑。
7. 执行前端测试、TypeScript 构建、Rust 格式化、Clippy、测试和桌面端构建。
8. 主线程以代码总监视角检查 diff，重点复核跨窗口通信清理、循环竞态、对比度和未使用代码。
