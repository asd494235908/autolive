# 本地媒体引擎与连续播放设计

> 文档状态：早期方案已废止（2026-08-13）。当前只保留单源视频、单窗口循环和当前音轨安全替换；本文中的下一项、队列和离线版本设计不得实施。

## 当前口径

当前产品首版是“单个源视频、单个窗口、显式循环播放”。视频处理、声音处理和实时音频幻化是三个独立开关；实时音频幻化只替换当前播放视频的基础音轨，普通声音处理作用于最终当前音轨，不生成下一项 MP4。本文早期设计中的“当前项/下一项、双媒体槽和连续预生成”仅供历史审计，不能作为当前默认播放流程。

## 目标

在已有本地能力基础上，保留两类能力设计：

1. 桌面端能够探测本机是否具备本地 FFmpeg/FFprobe 媒体引擎，并在具备时执行基础视频重编码、音频增益和倍速处理；
2. 播放端只维护一个源视频和当前音频候选；当前首版在同一窗口回到源视频 0 秒循环，并支持当前基础音轨安全替换和普通声音处理。

本设计文档记录媒体引擎纵切片基线；后续已分别接入受控 ASR、TTS、对齐、mux 和研究 Worker 契约，但本地研究算法仍不由 Rust 实现。完整算法、所有实验参数的实际生效和 RTMP/OBS 均不属于本设计；媒体引擎只用于本地文件处理，不启动推流、不上传视频、不执行 shell 命令。

## 边界

下列“下一项、缓冲等待和双媒体槽”条目均属于未来离线 N 版；当前首版只维护一个源视频和一个当前音频轨道。

- FFmpeg/FFprobe 默认从 PATH 探测，也可由桌面进程通过 `AUTOLIVE_FFMPEG_PATH`/`AUTOLIVE_FFPROBE_PATH` 指定绝对路径；前端不能传入任意可执行命令；进程通过 `Command` 参数数组启动，不经过 shell。
- 源 MP4 只读；输出写入应用数据目录下的任务 staging，完成后以“不覆盖”的方式提交到版本目录。
- 启用视频效果时必须走解码和重新编码，渲染参数不能生成 `-c copy` 或等价的视频流复制参数。
- 第一批只支持基础可验证参数：亮度、对比度、饱和度、色相、缩放、输入/输出音量、音频倍速；其余参数进入参数模型但不在本轮宣称生效。
- 未安装媒体引擎时返回结构化 `media_engine_unavailable`，任务阶段上报失败，不生成假 MP4。
- 本地渲染进程设置 6 小时安全时限；取消、超时和异常等待路径必须回收子进程并清理 partial 文件。
- 连续播放只操作同一个现有窗口和媒体元素；下一项不可播放时保留当前画面/状态并显示缓冲等待或原声回退原因。

## 数据流

以下“ready candidate/同一窗口安全切换”仅用于未来离线 N 版；当前首版的媒体流是 `源 MP4 → 可选视频处理缓存 → 单窗口从 0 秒循环`，当前音频换轨由实时音频幻化契约单独负责。

```text
源 MP4
  │ prepare：元数据 + 完整 SHA-256
  ▼
媒体引擎探测 ──不可用──> 结构化失败，不写输出
  │可用
  ▼
构造无 shell 的 FFmpeg 参数
  ▼
staging/variant.partial.mp4
  │ 容器可读性 + 完整文件 SHA-256
  ▼
不覆盖提交到 outputs/vXX.mp4
  ▼
播放协调器登记为 ready candidate
  ▼
同一窗口在安全边界切换
```

## 接口边界（未来离线 N 版扩展）

Rust 核心：

- `probe_media_engine() -> MediaEngineStatus`
- `build_render_plan(request) -> RenderPlan`
- `render_variant(request, work_root, cancellation) -> RenderVariantResult`
- `ContinuousPlaybackCoordinator::mark_next_ready(...)`
- `ContinuousPlaybackCoordinator::mark_next_failed(...)`
- `ContinuousPlaybackCoordinator::on_current_ended(...)`

Tauri：

- `probe_media_engine`
- `render_variant_task`
- `mark_next_playback_ready` / `mark_next_playback_failed`（携带 `playback_generation`，拒绝过期事件）

React：

- 在任务面板展示媒体引擎状态和不可用原因；
- 只允许提交本地可播放且已哈希的输出；
- 在同一窗口维护当前/下一项两个媒体槽，预加载下一项并切换激活槽，不创建第二个弹窗；
- 使用真实 `video.buffered` 计算缓冲秒数；播放批次变化后，旧事件不能覆盖当前队列；
- 当前项结束时若下一项未 ready，不切换到空地址，并展示缓冲状态。

## 验收（未来离线 N 版扩展）

- 单元测试验证引擎版本解析、参数校验、FFmpeg 参数不含复制编码、输出路径不越界和已有输出不覆盖。
- 没有 FFmpeg 时，探测结果为 unavailable，渲染返回结构化错误且没有输出 MP4。
- 有可用引擎时，使用测试 MP4 生成一个重新编码输出，输出可再次探测，源文件 SHA-256 不变，输出 SHA-256 与源不同。
- 播放协调器测试覆盖：首项立即可播放、下一项 ready 才切换、下一项未 ready 时等待、失败时回退原声/备用项、同一窗口 ID 不变。
