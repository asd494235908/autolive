# 媒体参数与本地阶段能力契约

> 文档状态：参数部分仍可参考，媒体任务阶段部分已废止（2026-08-13）。当前产品不创建媒体任务或离线版本；以根目录的媒体参数契约和桌面端功能流程图为准。

## 当前口径

当前首版参数面板服务于一个源视频的本地循环预览。视频处理、声音处理和实时音频幻化是独立开关；实时幻化的输出是当前播放基础音轨，普通声音处理作用于最终当前音轨，不生成 N 个 MP4。本文的 `rewrite/tts/align/mux` 阶段能力仅供历史审计。

## 状态

已实现参数模型和能力查询的第一版契约。实际音频算法、ASR、LLM、TTS、对齐算法仍由后续阶段接入；研究分析已接入受控 Worker 契约，真实研究算法仍需配置外部 Worker。

## 目标

- 将竞品截图中的配置值、运行时测量值、资源统计和倒计时分开。
- 让音频、视频和研究参数拥有稳定字段、单位、范围和默认值。
- 在本地依赖未安装或未配置时，返回 `unavailable`，禁止把未执行阶段标成 `succeeded`。
- 为后续 Worker、Tauri IPC 和控制面阶段事件复用同一套阶段顺序与重试语义。

## 参数边界

Rust 参数模型位于 `desktop/src-tauri/src/research_params.rs`，只负责：

- `Serialize/Deserialize`；
- 默认值；
- 固定视觉频段集合 `65/92/131/188/267/381/544/777/1110/1585/2263/20000 Hz`；
- 字段范围、单位和跨字段关系校验；
- 结构化校验错误。

它不执行音频变声、频谱、MFCC、视频滤镜、隐形标记或随机扰动算法，也不生成随机值。

相位扰动按相对百分比记录；SNR、共振峰等当前值必须作为只读测量字段，不与配置幅度共用字段。

## 阶段能力

Rust `stage_pipeline` 固定阶段顺序：

`prepare → transcribe → rewrite → tts → align → mux → research`

参数校验命令为 `validate_local_research_params`。桌面端提交的参数先映射到 Rust `LocalResearchParams`，返回 `valid` 和结构化 `errors`；验证通过不代表算法已经执行。

本地能力查询命令为 `get_local_stage_capabilities`：

- `prepare`：当前本地准备清单能力；
- `transcribe`：需要 `AUTOLIVE_ASR_COMMAND`；
- `rewrite`：需要 `AUTOLIVE_MODEL_PROXY_URL`；
- `tts`：需要 `AUTOLIVE_TTS_COMMAND`；
- `align/mux`：需要 FFmpeg/FFprobe 能力探测成功；
- `research`：需要 `AUTOLIVE_RESEARCH_COMMAND`；Worker 必须返回与输入/输出 MP4 完整 SHA-256 一致的结构化研究报告。

能力不可用只影响下一阶段是否可启动，不影响当前正在播放的源媒体。阶段状态允许 `failed → running` 重试；`succeeded` 和 `cancelled` 为终态，不能被静默覆盖。

## 桌面端表现

桌面端参数面板使用 Ant Design 组件，显示：

- 音频参数、视频参数、视觉频段、挂件与切片参数；
- 单位、范围、默认值来源和研究模式提示；
- 原始 SHA-256、当前阶段产物 SHA-256、算法版本和随机种子诊断字段；
- 本地阶段能力的真实可用/不可用状态。

面板只保存参数和调用回调，不宣称参数已经生效。当前本地媒体 Worker 已映射基础视频画面参数、动态裁剪/像素扰动/空间偏移，以及响度、采样率和源采样率可用时的音高微移；MFCC、SNR、共振峰、滤波 Q、相位、帧率微扰、视觉频段和挂件仍由专用 Worker 承担。

## 失败与恢复

- 参数越界：在 Rust 校验层拒绝；不得写入阶段产物。
- 固定频段缺失或多余：拒绝参数树。
- 切片触发间隔小于切片长度：拒绝参数树。
- 外部依赖未配置：能力返回 `available=false` 和稳定 `reason_code`，不提交成功事件。
- 已生成的阶段产物不覆盖；后续 Worker 必须使用临时文件和阶段清单提交。
- 研究 Worker 失败、取消、超时、报告校验失败或双产物提交失败时，必须清理所有 partial 文件和已提交的同批报告，不留下半成品。
