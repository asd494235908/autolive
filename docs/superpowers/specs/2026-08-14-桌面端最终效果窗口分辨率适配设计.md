# 桌面端最终效果窗口分辨率适配设计

> 当前版本范围声明（2026-08-19）：本版本不开发实时话术幻化；本文窗口适配不包含 speech-to-speech、实时话术候选或实时换轨。

## 1. 目标

让独立的 `final-effect` 播放窗口根据当前选择的视频分辨率适配窗口尺寸：

- 正常情况下，窗口内容尺寸跟随视频宽高。
- 视频分辨率超过当前显示器可用区域时，窗口和视频保持宽高比等比缩小。
- 视频切换或处理后视频切换时，复用同一个窗口并更新尺寸，不重新创建窗口。
- 维持现有最小窗口约束，避免极小视频导致窗口不可操作。

## 2. 非目标

- 不改变视频编码、播放循环或播放状态机；文中音频候选切换仅指历史/后续版本兼容边界，本版本不验收实时话术候选或换轨。
- 不创建多个播放窗口，不通过销毁并重建窗口实现换源。
- 不裁剪、拉伸或修改视频内容的宽高比。
- 不承诺跨显示器拖动后的复杂布局持久化；本轮只适配当前窗口所在显示器。

## 3. 当前上下文

- Rust 在 `open_final_effect_window` 中以固定 `1280×760` 创建 `final-effect` 单实例窗口。
- `SourceMediaDto` 和前端 `PlaybackSnapshot.source_media` 已包含可选的 `width`、`height`。
- 播放窗口通过 `get_snapshot` 读取 Rust 播放状态，当前视频引用变化时更新 `<video>` 源。
- 播放窗口的窗口权限已包含 `final-effect`，现有 IPC 命令通过窗口标签限制播放操作。

## 4. 设计

### 4.1 单一尺寸计算入口

新增受限的 Tauri 窗口调整命令，接收当前视频的正整数宽高。命令只允许由 `main` 或 `final-effect` 播放窗口调用，并拒绝零值、超出安全范围或无法计算的尺寸。

Rust 负责：

1. 读取当前 `final-effect` 窗口所在显示器的可用工作区。
2. 以视频原始宽高为目标，按工作区宽高计算最大等比缩放比例，比例不大于 `1`。
3. 应用最小窗口尺寸约束；若最小尺寸会破坏宽高比，则以满足最小可操作尺寸且尽量保持比例的结果为准。
4. 设置窗口内容尺寸并重新居中；窗口不存在、显示器信息不可用或系统调用失败时返回结构化错误。

前端不自行计算显示器尺寸，只在 `snapshot.source_media.width/height` 变化或当前视频源变化时调用该命令。通过 ref 记录最近一次成功调整的宽高，避免 500ms 快照轮询重复调整窗口。

### 4.2 生命周期与换源

- `open_final_effect_window` 继续保持单实例行为。
- 首次打开时，窗口先使用现有安全默认尺寸；播放窗口拿到有效视频元数据后立即调整到目标尺寸。
- `current_video_reference` 或 `source_media.width/height` 变化时，复用窗口并重新调用调整命令。
- 视频尺寸缺失时不调整窗口，继续使用当前尺寸播放。
- 调整失败只记录当前 UI 错误/诊断，不阻塞视频播放、不关闭窗口、不清空当前媒体源。

### 4.3 视频呈现

视频播放区域保持源视频宽高比，使用 `contain` 作为安全兜底，不裁剪、不拉伸。现有控制按钮和状态区域继续保留；窗口外框会为这些 UI chrome 保留固定附加空间，因此“窗口和视频一致”具体表现为窗口与视频保持同一宽高比、视频完整显示，且控件不会被窗口边界裁切。

## 5. 数据流

```text
probe_local_mp4
  -> SourceMediaDto.width/height
  -> PlaybackSnapshot.source_media
  -> final-effect 监测当前视频尺寸/引用
  -> resize_final_effect_window(width, height)
  -> Rust 查询当前显示器工作区并等比缩放
  -> 复用 final-effect 窗口播放
```

## 6. 错误与边界

- 宽高为空、为零、超过安全上限：忽略本次调整并返回 `invalid_video_dimensions`。
- 当前显示器不可用：返回 `final_effect_monitor_unavailable`，保留当前窗口尺寸。
- 设置窗口尺寸或居中失败：返回 `final_effect_window_resize_failed`，保留当前窗口尺寸。
- 视频源路径、播放状态和窗口生命周期不受尺寸调整失败影响。
- 多次相同尺寸请求必须幂等；前端去重，Rust 命令本身也不依赖调用次数产生额外状态。

## 7. 测试与验收

### Rust 单元测试

- 正常视频尺寸在工作区内时，结果保持原始宽高比例。
- 超过工作区时，结果按较小比例等比缩小。
- 零值、负值、超出上限尺寸被拒绝。
- 最小尺寸约束不会产生零尺寸或溢出结果。

### 前端/集成测试

- 源视频元数据尺寸变化只触发一次调整请求。
- 相同宽高的 500ms 快照轮询不会重复调整。
- 视频源切换会调整同一个窗口，不调用创建窗口逻辑。
- 调整命令失败时视频仍可播放，窗口保持原尺寸。

### 手工验收

- 使用 640×360、1280×720、1920×1080 和竖屏视频分别验证。
- 使用超过屏幕可用区域的 4K 视频验证等比缩小和完整显示。
- 在窗口切换视频源时确认无新窗口、无黑屏、无明显停顿。
