# 主页播放控制与纯画面播放器设计

## 1. 目标

将独立播放器窗口中的浏览器原生控制迁移到桌面端主页：

- 独立播放器正常播放时只显示视频画面和必要的隐藏音轨元素。
- 主页集中承载暂停、继续、停止、播放进度、音量、静音和画中画控制。
- 保留现有单窗口、单源循环、视频尺寸适配和 Rust 播放状态事实源。
- 主窗口与播放器窗口通过现有 `autolive-playback-ui-v1` `BroadcastChannel` 同步，不新增重复的 Rust 媒体状态。

## 2. 非目标

- 不创建第二个播放器窗口。
- 不把视频文件、音频文件或敏感信息放进跨窗口消息。
- 不新增播放器库、全局状态库或 Rust 媒体引擎。
- 不改变视频处理、声音处理、实时话术幻化、单源循环和窗口尺寸计算逻辑。
- 不在播放器窗口绘制自定义控件；播放器正常状态不显示控制条。

## 3. 窗口职责

### 3.1 主页面

`DesktopApp` 继续拥有页面控制状态，并新增由播放器上报的媒体状态：

- 当前播放时间、总时长；
- 当前音量、静音状态；
- 是否正在播放、是否支持画中画；
- 进度滑块、音量滑块、静音按钮、画中画按钮。

已有暂停/继续/停止按钮保持不变，并与新增控件放在同一张“播放状态与控制”卡片中。

### 3.2 独立播放器

`FinalEffectWindow` 只渲染可见 `<video>` 和隐藏 `<audio>`：

- 移除 `<video controls>`，避免 WebView 自动绘制画中画、音量和进度条。
- 继续由播放器元素持有真实 `currentTime`、`duration`、`volume` 和 `muted`。
- 播放器通过消息上报媒体状态；主页面只发送用户意图。
- 错误或无源时允许显示必要的错误/空状态提示，正常播放时不显示业务控件。

## 4. 跨窗口消息契约

沿用 `autolive-playback-ui-v1`，所有消息均要求 `version === 1`。

播放器发送：

```ts
type PlaybackMediaStateMessage = {
  version: 1;
  type: 'playback-media-state';
  current_time: number;
  duration: number;
  volume: number;
  muted: boolean;
  paused: boolean;
  picture_in_picture_supported: boolean;
  picture_in_picture: boolean;
};
```

主页发送：

```ts
type PlaybackMediaControlMessage =
  | { version: 1; type: 'playback-media-control'; action: 'seek'; current_time: number }
  | { version: 1; type: 'playback-media-control'; action: 'set-volume'; volume: number }
  | { version: 1; type: 'playback-media-control'; action: 'toggle-muted' }
  | { version: 1; type: 'playback-media-control'; action: 'picture-in-picture' };
```

边界校验要求：时间和音量必须是有限数；时间不小于 0；音量限制在 0 到 1；布尔字段必须为布尔值；未知消息直接忽略。播放器对 `seek` 再按实际 `duration` 进行夹取。画中画能力不可用时，主页按钮禁用并显示清晰状态，不影响普通播放。

## 5. 状态同步

- 播放器在 `loadedmetadata`、`timeupdate`、`durationchange`、`play`、`pause`、`volumechange` 和 `ended` 时上报状态。
- 为避免进度拖动产生高频跨窗口消息，主页拖动时只发送当前值；播放器在收到后立即设置 `currentTime`，随后由媒体事件回报实际值。
- 主页面收到媒体状态后只更新展示状态，不覆盖 Rust `PlaybackSnapshot`。
- 主页控件在没有播放器状态或通信通道不可用时禁用；已有 Rust 暂停/继续/停止命令仍可用。

## 6. 验收条件

1. 播放器窗口 DOM 中的视频元素没有 `controls` 属性，正常播放画面不出现底部进度条、音量条和画中画按钮。
2. 主页可以查看并拖动播放进度，播放器画面跳转到对应位置。
3. 主页音量和静音操作同时作用于原始视频音轨及候选音轨；恢复/切换候选音轨后设置不丢失。
4. 主页画中画按钮可以请求播放器视频进入/退出画中画；不支持时按钮不可操作并给出状态提示。
5. 暂停、继续、停止和循环行为保持现状，未打开播放器或播放器通信失败不导致主页崩溃。
6. 使用 `/Users/mac/Downloads/f2b22cf8a926741ac9ddbd6978455c58.mp4` 手工验证：弹窗只剩视频画面，主页控制生效，竖屏画面尺寸适配不回退。
