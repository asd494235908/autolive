# 桌面端三列工作台设计

> 当前版本范围声明（2026-08-19）：本版本不开发实时话术幻化。本文页面设计中出现的实时话术设置、Worker 状态和候选音轨仅作历史/后续版本参考；当前三列工作台只展示普通声音处理、插话、固定话术朗读和视频处理能力。

## 背景

当前桌面端主页面把素材导入、播放状态、声音处理、视频处理和实时诊断按纵向卡片连续排列。用户需要把页面改成三列工作台，让视频素材状态、音频设置和视频处理参数形成稳定的视觉分区；主页不展示实际视频画面。

现有 Rust/Tauri 播放状态机和媒体处理命令继续作为当前业务事实源；实时音频候选链路仅作历史兼容审计。本地声音/视频研究分析不属于当前页面能力。本次只调整 React 页面组织和主题配置，不重新设计媒体能力。

## 目标

- 使用三列工作台布局，宽屏列比例为 28% / 38% / 34%。
- 左列负责导入视频和展示视频状态。
- 中列负责普通声音处理设置、插话/固定话术入口和波形/频谱诊断；不展示实时话术设置。
- 右列负责视频处理设置和实时视频参数预览，不展示实际视频画面。
- 使用 Ant Design 默认亮色主题，移除当前页面自定义的深色 Token 和自定义青色主色。
- 保持现有导入、播放、视频/普通声音处理开关、画中画、媒体 Worker 状态和错误处理行为不变；不新增实时话术入口。

## 非目标

- 不修改 Rust/Tauri 命令、播放状态机或媒体处理流程。
- 不新增 API、数据库表、媒体任务、版本队列或离线视频版本。
- 不引入新的组件库、状态管理库或测试框架。
- 不改变视频/普通声音两个当前处理开关的独立性和失败回退语义；实时话术幻化本版本不提供入口。

## 页面结构

### 左列：素材与视频状态（28%）

保留并集中现有以下内容：

- “导入视频并播放”与“打开/聚焦播放器”。
- 当前源素材文件名、时长、格式、文件大小和 SHA-256 状态。
- 播放状态、循环次数、当前视频、当前音轨和处理状态。
- 暂停、继续、停止、进度、静音、音量和画中画控制。
- 导入失败、播放状态读取失败、播放器不可用等面向用户的错误提示。

导入成功后保持 `Ready`，用户点击“播放”才打开/聚焦唯一最终效果窗口并开始单源播放；源视频随后在同一窗口内循环，页面布局不能引入新的媒体队列或等待处理产物才能开始播放。

### 中列：声音设置（38%）

保留并集中现有以下内容：

- 声音处理开关；实时音频幻化本版本不提供入口。
- 当前媒体处理参数应用入口，但仍遵守声音处理独立开关。
- 固定话术系统朗读状态、插话状态和普通声音处理失败回退提示；不展示实时音频候选状态。
- 固定话术、插话和准备/替换/取消/清空操作。
- 音频动态运行时参数、波形、频谱和采样诊断。
- 音频参数校验和恢复默认操作；研究参数不属于当前页面。

所有控件继续调用现有事件处理函数和 Tauri 命令；布局调整不改变参数范围、默认值和不可用能力的提示。

### 右列：视频处理与实时参数（34%）

保留并集中现有以下内容：

- 视频处理开关、视频媒体引擎状态和处理参数应用结果提示。
- 运行时视频参数快照，包括亮度、对比度、饱和度、色相、模糊、缩放和空间位移。
- 当前已接入的视频参数、视频处理状态和错误/回退摘要；视频研究参数和研究报告不属于当前页面。

主页不展示实际视频画面；保留一个不可见的媒体元素，仅供现有画中画按钮同步媒体源和播放位置使用，且不自动播放。

右列的实时参数预览是当前运行值的可读展示；用户调整视频参数时通过现有媒体参数状态和校验流程完成，不复制出第二份状态。

## 状态与数据流

- `DesktopApp` 继续作为页面状态所有者，保留现有 `probe`、`snapshot`、媒体参数、运行时预览和 Worker 能力状态；不新增研究参数状态。
- 三列只负责按职责呈现状态、派发用户操作和显示错误，不建立新的全局 Store。
- `snapshot` 继续由 `get_snapshot` 轮询刷新；主窗口和最终效果窗口之间的 BroadcastChannel 不变。
- 主题调整只涉及 `desktop/ui/src/main.tsx` 的 `ConfigProvider` 配置。
- 布局样式使用页面自身的布局规则，不覆盖 `.ant-*` 内部选择器，不修改 Ant Design 组件内部行为。

## 响应式策略

- 宽屏使用三列 28% / 38% / 34%，列间保留稳定间距。
- 中等窗口保留三列，但每列内部允许独立滚动，避免某一列的参数面板撑高整个页面。
- 窄窗口按左列、中列、右列顺序堆叠为单列，关键状态和操作不隐藏。
- 每列保留标题、加载、空、错误、禁用和只读状态。
- 交互继续使用 Ant Design 原生按钮、开关、滑块、输入和提示组件，保留键盘焦点和可访问名称。

## 文件职责

- `desktop/ui/src/App.tsx`：调整 `DesktopApp` 的 JSX 分区和页面布局，复用现有状态与事件处理。
- `desktop/ui/src/main.tsx`：移除自定义主题 Token，恢复 Ant Design 默认亮色主题。
- 如现有内联样式无法表达响应式规则，再新增一个仅负责页面布局的样式文件；不创建通用 `utils`、`shared` 或大杂烩组件目录。

## 验收标准

1. 宽屏页面可清晰看到左、中、右三列，实际职责分别为素材状态、声音设置、视频处理与实时参数；主页不展示实际视频画面。
2. 三列宽度比例接近 28% / 38% / 34%，列间没有横向溢出。
3. 窄窗口按左→中→右顺序堆叠，导入、播放、开关和错误提示仍可访问。
4. 页面使用 Ant Design 默认亮色主题，不再显示当前自定义深色背景和青色 Token。
5. 导入视频后保持 `Ready`，用户点击播放才进入同一窗口单源循环播放，不生成额外视频版本。
6. 视频处理和普通声音处理两个当前开关仍可独立切换；实时话术幻化本版本不提供开关。
7. 执行 `pnpm build` 和 `pnpm test` 通过；不引入新的未使用导入、组件、类型、样式、依赖或调试日志。
