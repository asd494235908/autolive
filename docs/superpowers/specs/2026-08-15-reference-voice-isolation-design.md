# 参考人声自动分离与片段选择设计

## 目标

让固定话术播放使用更准确的人声参考音频。导入视频后默认提取第一条音轨，并通过 Demucs 的 vocals 两 stems 输出去除背景音乐的人声；不再盲目截取分离音频的前 30 秒，而是根据 Whisper 识别到的语音段自动选择人声密度最高的窗口。

## 范围

- 保留现有本地 CPU Demucs + faster-whisper + XTTS-v2 链路。
- 默认执行人声分离，不增加新的用户开关。
- 参考窗口最长 30 秒，起点和终点来自有效 Whisper 语音段，优先选择语音总时长最长、语音密度更高的窗口。
- 没有有效语音段时失败并返回明确原因，禁止回退使用含背景音乐的原始音频。
- 保持完整分离人声音频用于转写和话术索引。

## 非目标

- 不更换 XTTS-v2 或 Demucs 模型。
- 不新增手动波形剪辑 UI。
- 不重新编码视频、不改变固定话术播放和视频循环逻辑。
- 不新增服务器端处理或上传音频。

## 数据流

1. FFmpeg 从源视频选择 `0:a:0`，转成 16kHz 单声道 WAV。
2. Demucs 使用 `--two-stems=vocals` 生成 `vocals.wav`，该文件是唯一的人声来源。
3. Whisper 对完整 `vocals.wav` 转写并过滤空文本、过短片段。
4. 在 30 秒上限内扫描语音段窗口，选择语音覆盖时间最长且密度更高的窗口。
5. FFmpeg 从 `vocals.wav` 裁剪该窗口，生成 XTTS 参考音频。
6. 无有效片段时返回失败，不调用 XTTS。

## 验收条件

- 音乐片头后才开始说话的素材，参考音频起点不再固定为 0 秒。
- 语音密集片段优先于只有少量语音的片段。
- 参考音频裁剪命令包含自动选择的起点和时长，且不超过 30 秒。
- 无有效语音段时返回 `未检测到有效人声片段`。
- 现有 Worker 单元测试、Rust 测试和 UI 构建不回归。
