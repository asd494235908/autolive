# 模型号池与客户端租约最小闭环设计

> 文档状态：历史实现设计（2026-08-13）。当前产品已确定 Go 负责 OpenAI-compatible 账号登记/连通性测试和直连租约管理，Rust 使用单账号短期直连租约调用模型；本文仅供审计，不能作为当前实现依据。

## 目标

补齐早期 PRD 中“管理员配置模型号池、客户端按需申请模型资源”的最小真实闭环，作为历史实现审计材料。

本批次只实现资源配置与短期租约，不实现真实供应商请求、LLM 文本改写、PostgreSQL 持久化或密钥加密存储。

## 边界与安全约束

- 管理员通过 `POST /api/v1/admin/model-pool` 新增模型账号配置。
- `api_key` 只在 Go 进程内存中保存，用于开发阶段状态；不写日志、不返回 API、不进入 React 构建物。服务重启后配置丢失，生产环境必须替换为加密 Secret Store。
- `GET /api/v1/admin/model-pool` 只返回摘要和 `secret_configured`，不返回密钥、完整号池或租约凭证。
- 客户端通过 `POST /api/v1/client/model-leases` 申请 `server_proxy` 租约；客户端不取得供应商 API Key。
- 租约必须绑定已激活的用户和设备；只能由所属用户/设备续租或释放。
- 同一账号的活动租约数不得超过 `concurrency_limit`；过期租约在读取/申请/续租时惰性回收。
- 所有写操作使用 `Idempotency-Key`；相同幂等键请求语义不同必须返回冲突。
- 续租和释放是幂等的；释放后不得再次续租，过期租约不得续租。

## 数据与接口

### 管理端

`POST /api/v1/admin/model-pool`

```json
{
  "provider": "openai-compatible",
  "model": "rewrite-model",
  "api_key": "仅开发内存使用",
  "priority": 10,
  "daily_limit": 1000,
  "concurrency_limit": 2
}
```

响应只返回账号摘要：`id/provider/model/status/priority/daily_limit/concurrency_limit/secret_configured`。

`GET /api/v1/admin/model-pool` 返回账号摘要数组和 `request_id`。

`POST /api/v1/admin/model-pool/{account_id}/disable` 禁用账号；若账号仍有活动租约，返回 `MODEL_POOL_ACCOUNT_IN_USE`，要求先释放租约。接口使用 `Idempotency-Key`，成功后账号状态为 `disabled`，不会再被新租约选中。

### 客户端租约

`POST /api/v1/client/model-leases`

```json
{
  "provider": "openai-compatible",
  "model": "rewrite-model",
  "purpose": "rewrite",
  "max_duration_seconds": 300
}
```

返回 `ModelLease`：`id/provider/model/status/expires_at/proxy_mode/server_proxy/concurrency_limit`。本批次不返回 `client_token`。

`POST /api/v1/client/model-leases/{lease_id}/renew` 支持 `extend_seconds`；`POST /release` 释放租约并返回 `released`。

## 前端与桌面端

- 管理端号池页面使用 Ant Design Table、Form、Modal，覆盖 loading、empty、error、重试和新增成功提示；密钥输入使用密码控件，页面不显示已保存密钥。
- 桌面端只增加租约 API client 和最小状态展示/申请释放动作，不把租约当成真实模型调用成功；未申请成功不得进入后续 `rewrite`。
- 租约错误显示稳定错误码和 request_id，网络失败不影响本地播放。

## 验收

- Go 测试覆盖：管理员新增与摘要脱敏、无可用账号、并发上限、用户/设备归属、租约幂等、续租、释放、过期回收和禁用状态。
- 管理端类型检查、构建通过，页面不再显示“功能建设中”。
- 桌面端 TypeScript 构建通过，申请/释放只调用已定义接口。
- 明确记录：没有真实供应商代理和持久化密钥时，不宣称 `rewrite` 或大模型调用已完成。
