# 错误码

> 当前版本范围声明（2026-08-19）：本版本不开发实时话术幻化。`speech-to-speech` Worker、候选音轨和实时话术换轨错误仅保留为历史/后续版本兼容错误；当前错误处理以本地视频、普通声音、插话、固定话术朗读和播放窗口为准。

本文件定义三端共享的稳定错误码、HTTP 状态和默认处理建议。服务端必须返回统一结构：

```json
{
  "code": "MEDIA_WORKER_UNAVAILABLE",
  "message": "本地媒体 Worker 当前不可用",
  "request_id": "req_01J..."
}
```

约束：

- `code` 稳定、可枚举，供 Go/React/Rust 分支处理。
- `message` 可面向人阅读，但不作为程序分支依据。
- `request_id` 必填，用于日志、审计和用户报障。
- `details` 可选，只用于字段级校验。

客户端本地错误：`CONTROL_PLANE_TIMEOUT` 由桌面端请求封装在本地超时时生成，不是 Go 服务返回的 API 错误码；它只表示本次 HTTP 结果未知，涉及租约或调用摘要时不得自动生成新的幂等键。

当前产品不定义离线媒体任务、版本数量和阶段事件错误码。当前错误码覆盖登录、设备、激活、模型账号测试、控制面租约、调用摘要、本地媒体 Worker 和桌面播放命令；实时音频换轨与桌面端本地直连模型错误仅作后续版本兼容定义，本版本不触发。

## 通用规则

| HTTP | 语义 | 默认客户端处理 |
| --- | --- | --- |
| `400` | 参数校验失败 | 阻止继续提交，定位字段并提示用户修正 |
| `401` | 未登录、Access Token/Refresh Token 失效 | 清理会话，跳转登录或尝试刷新 |
| `403` | 已登录但无权限，或用户/设备/激活状态不可用 | 停止受保护能力，提示联系管理员 |
| `404` | 资源不存在 | 提示资源失效并刷新列表/状态 |
| `409` | 状态冲突、重复语义不一致、幂等冲突 | 拉取最新状态后再决定重试 |
| `429` | 并发、额度或频率限制 | 指数退避，展示稍后重试 |
| `500` | 未分类服务端异常 | 记录 `request_id`，提示稍后重试 |

## 推荐的三端策略

### React 管理端

- `401`：退出当前会话并返回登录页。
- `403`：保留页面上下文，提示权限不足或资源不可用。
- `409`：优先刷新列表或详情，不盲目重试。
- `503/AUDIT_UNAVAILABLE`：若原请求带 `Idempotency-Key`，只使用同一 key 自动重试一次；没有幂等键时不得自动重放写请求。

### Rust/Tauri 客户端

- 心跳、租约、模型账号测试和直连调用摘要写接口都必须带 `Idempotency-Key`。
- 网络失败重试必须沿用同一次用户操作的原 `Idempotency-Key`；只有请求语义或资源标识变化时才生成新 key。
- `503/AUDIT_UNAVAILABLE`：只使用同一 key 自动重试一次；响应仍未知时停止自动重放并保留状态供恢复流程核对。
- `TOKEN_EXPIRED`：优先刷新会话；失败再降级到登录态。
- `DEVICE_DISABLED` / `USER_DISABLED`：停止模型调用、任务启动和激活外的受保护操作。
- `MEDIA_CANDIDATE_STALE` / `MEDIA_SYNC_GATE_FAILED`：丢弃候选并继续上一条可用音轨，不暂停视频、不重新弹窗。

### Go 服务实现约束

- 不使用自由文本作为错误契约。
- 同一个错误码在不同接口中的业务语义必须一致。
- 不返回完整模型密钥、不返回大视频上传重试建议。
