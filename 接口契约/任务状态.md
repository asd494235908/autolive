# 播放状态与实时音频状态契约

> 当前版本范围声明（2026-08-19）：本版本不开发实时话术幻化。本文件中的实时音频状态、speech-to-speech Worker 和候选换轨状态仅作历史/后续版本契约保留，不属于当前播放状态、UI、验收或发布范围。当前版本只以单源视频播放、普通声音处理、插话和固定话术系统朗读为准。

当前产品不创建离线媒体任务，不计算版本数量，不生成多个 MP4，也不维护视频版本队列。本文件当前有效部分只定义 `.mp4`、`.mov`、`.mkv`、`.avi`、`.webm`、`.m4v`、`.ts`、`.m2ts`、`.flv`、`.wmv`、`.3gp` 单源视频在同一窗口内循环播放；实时话术幻化状态章节仅作后续版本/历史契约，本版本不开发。

## 1. 播放状态

| 状态 | 含义 |
| --- | --- |
| `ready` | 已登录且当前设备的账号授权有效，可以选择本地源视频 |
| `loading` | 正在探测源视频或读取元数据；需要完整哈希的媒体处理提交按对应阶段计算 |
| `playing` | 当前源视频正在同一窗口播放 |
| `paused` | 当前播放已暂停 |
| `stopped` | 当前播放已停止，但源视频和参数仍保留 |
| `offline_playing` | 控制面暂时断开，但本地播放继续 |
| `error` | 源视频不可读、媒体引擎不可用或播放发生不可恢复错误 |

`disabled` 属于控制面授权状态，不属于 `PlaybackState`。用户或设备被禁用时，客户端停止受保护的模型/后台操作；已打开的本地播放是否停止由产品授权策略单独决定。

播放结束时，播放器在同一窗口将当前源视频定位到 `0` 秒并递增 `loop_index`，再次进入 `playing`。这不是切换视频版本，也不创建第二个窗口。


约束：

- `source_media.mp4_sha256` 只在源文件实际为 MP4 且进入对应哈希链路时记录整个 MP4 文件字节流 SHA-256；当前导入探测默认保持 `disabled`。非 MP4 源文件不得写入该字段。
- `current_mp4_sha256` 是当前画面产物的整个 MP4 文件 SHA-256；本版本不因实时话术换轨产生音频候选，相关音频哈希字段如仍存在只作兼容保留。
- `current_video_reference` 是当前窗口正在播放的源视频或处理缓存；`pending_video_reference` 是后台处理完成但尚未提交的候选缓存。当前视频处理校验成功后立即切换 `current_video_reference`，不把下一轮循环边界作为必要前置。
- 当前两个开关互相独立：视频处理和普通声音处理不能隐式开启或关闭其他开关；实时话术幻化本版本不提供入口。
- 源视频不可读或媒体引擎不可用时，必须返回结构化错误，不返回伪造的播放成功；若媒体处理阶段启用了完整哈希，哈希失败不停止已开始的本地原声播放，但必须阻止对应阶段提交并显示错误。

视频/普通声音处理状态：`disabled`、`processing`、`ready`、`runtime`、`failed`、`unavailable`。`runtime` 表示普通声音处理作用于普通源音轨的当前 PortAudio 出口；PortAudio 关闭/失败时回退 WebView 源音频；未接入运行时 DSP 的高级参数必须显示 `unavailable`，不得静默跳过。视频处理 Worker 成功并通过校验后立即提交当前视频引用；取消、超时或失败时保持当前可用视频，不覆盖源文件。

## 3. 实时音频状态（后续版本/历史契约，本版本不开发）

本节不属于当前播放状态机。当前版本不启动 speech-to-speech、VAD、ASR、LLM、TTS，不生成候选音轨，也不进行实时换轨；代码中如仍保留字段或状态，只用于兼容审计。

| 状态 | 含义 |
| --- | --- |
| `disabled` | 实时话术幻化开关关闭，不启动 Worker |
| `idle` | 已开启，等待当前音频片段 |
| `capturing` | 正在从文件或受控实时流读取音频 |
| `processing` | speech-to-speech Worker 正在执行 VAD/ASR/LLM/TTS |
| `candidate_ready` | 候选音轨已生成并暂存，等待同步和安全门禁提交 |
| `switched` | 候选通过门禁，已替换当前播放音轨 |
| `fallback` | 候选失败、超时或不安全，继续使用上一条可用音轨 |
| `error` | Worker 或模型发生需要用户处理的错误 |

实时链路固定为：

```text
文件/受控实时流
    ↓
speech-to-speech Worker（VAD → ASR → LLM → TTS）
    ↓
LLM 决策：沿用当前内容 / 改写当前内容
    ↓
音频候选
    ↓
采样率、声道、时长、延迟、完整哈希和播放代际门禁
    ├─ 通过：替换当前基础音轨，再按声音处理开关输出最终音轨
    └─ 失败：保持上一条可用音轨并记录回退原因
```

LLM 不能及时完成时，视频和上一条可用音轨继续播放。实时幻化不暂停视频、不静音、不切换空媒体源、不重新弹窗。

## 4. 开关与状态转换

```text
ready
  └─ 导入源视频 → loading → playing
                              ├─ 播放结束 → playing（loop_index + 1）
                              ├─ 暂停 → paused → 继续 → playing
                              ├─ 停止 → stopped
                              └─ 错误 → error → 重试或回退
```

实时话术幻化是播放状态的独立子状态，不改变主播放状态：

```text
disabled → idle → capturing → processing → candidate_ready → switched
                                      └──────────────────────→ fallback
```

关闭开关时，停止新的实时候选生成；已在生成中的 Worker 按取消协议终止并回收资源，当前视频继续播放。

## 5. 正式媒体参数能力状态

参考图中的声音、视频、视觉频段、不可见水印、随机扰动、挂件和切片参数属于正式 `MediaEffectParams` 契约。执行状态必须区分“已实现并生效”“已有模型待接入”“正式需求但缺失”；配置保存或校验通过不能代替运行态。旧独立报告 Worker、状态轮询和 IPC 已删除，禁止重新引入；内容相似度、媒体鲁棒性、内容指纹、平台评分和检测规避结论不属于当前状态契约。

## 6. 管理端可见摘要

后台只展示控制面和设备摘要，不接收或处理视频文件：

- 用户、设备、激活状态
- 当前源视频名称、播放状态和播放轮次
- 视频/普通声音处理两个当前开关；实时话术开关仅为后续版本兼容字段
- （后续版本）实时音频 Worker 状态、当前音频来源、延迟和回退原因；本版本不展示或验收
- 模型租约、请求状态和用量摘要

后台不展示版本数量、版本进度、离线合成任务或多视频队列。
