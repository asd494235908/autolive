# 桌面端主页与 HTML 设计稿功能差异审计

审计日期：2026-08-26。对照对象为正式桌面端主页源码与当前 HTML 原型；当前浏览器运行的是原型，因此视觉证据用于确认原型现状，正式端差异以源码调用链为准。本审计已排除实时话术幻化、旧媒体任务/版本队列、RTMP/OBS 等当前版本非目标。

## 新设计规则与正式桌面端待同步项

| 优先级 | 新设计规则 | 正式桌面端当前实现 | 结论 |
| --- | --- | --- | --- |
| 已同步 | 普通声音周期默认 `3–5 秒` | `desktop/ui/src/runtime-parameter-scheduler.ts` 已使用 `3000–5000ms` 新配置默认值 | 既有有效本地保存值继续保留；视频默认仍为 `8–15 秒` |
| 已同步 | 随机插话“变化周期最小值/最大值”以秒输入 | `desktop/ui/src/App.tsx` 已在 UI 边界除以/乘以 `1000` | Rust/IPC 字段继续使用毫秒，不修改后端契约 |
| 已同步 | 视频与纯音频统一媒体池 | HTML 原型与桌面端均接受首批视频/纯音频白名单并使用“媒体”文案 | 正式 FFprobe、原子提交和失败保留旧池仍由 Rust 执行 |
| 已同步 | 声音与视频周期输入位于所属媒体 Card | HTML 原型移除左栏重复周期 Card，桌面端继续复用唯一周期状态与回调 | 插话周期保持只读并由插话配置控制 |
| 已同步 | 媒体参数按设计稿使用全宽四列密集网格 | 桌面端单媒体面板不再预留空泳道，普通声音、普通视频和高级视觉在设计宽度下统一四列展示 | 窄窗口仍按可用宽度自动降列；真实参数值和运行状态不使用原型示例数据 |
| 已同步 | 音频/画面标题副说明与周期状态同层展示 | 桌面端标题保留功能开关和应用入口，周期范围输入收拢到状态行 | 不改变真实回调、禁用条件和可访问标签 |
| 已同步 | PortAudio 草稿、已应用配置与运行状态分离 | 桌面端应用成功后才提交已应用值，失败保留草稿和旧配置 | 无设备、越界、未变化、忙碌或能力不可用时禁用应用；保留主页固定测试音 |
| 已同步 | 播放区顺序与最终窗口文案 | 桌面端为“事实 → 进度 → 动作”，连接后按钮显示“聚焦” | 所有真实回调、disabled 与 loading 保持不变 |
| 已同步 | 会话状态与参数分组摘要读取真实事实 | 桌面端仅在会话与设备确认通过后显示“设备已授权”，账号与授权到期取控制面快照；参数数量取正式定义表 | 不复制设计稿中的账号、剩余天数、设备配额、媒体条目或变化次数等示例数据 |

附件中的非空播放池、账号 `kangyun`、“授权剩余 364 天 · 设备 1/3”、PortAudio 设备与运行中状态均属于设计稿示例。正式桌面端继续按真实会话、媒体池、设备枚举和运行快照显示空态、错误态、禁用态或实时值；普通视频、高级视觉、普通声音分组仅同步结构与实际定义数量 `32/42/37`。

## 当前仍需后续补齐的正式功能

| 优先级 | 未在设计稿完整展示的功能 | 正式桌面端证据 | 原型现状 |
| --- | --- | --- | --- |
| 已同步 | 本周期实际声音预设与支路查看 | `desktop/ui/src/App.tsx` 读取普通声音已提交周期，并接收最终效果窗 `interlude-runtime` | 普通声音与插话都可查看本周期/本段实际抽中的 1–4 套预设及每支路 35 项当前值 |

播放池完整编辑已在主页播放池 Card 内补齐，不再使用管理抽屉。播放、暂停、继续和停止现为独立按钮，并按动作显示 loading；顶部按用户最新决定只保留主页，不再把“设置/状态”视作待补路由。普通声音“四项可编辑基线”已取消，不再作为缺口。正式桌面端目前已经实现固定话术最多 10 条预制 CRUD、停止朗读和独立状态（`desktop/ui/src/App.tsx:7294-7337`），但用户此前明确要求下个版本再做，因此仍作为刻意延后项，不计入当前设计稿缺口。

媒体引擎不可用、视频处理失败、声音处理失败和随机插话失败的条件式就近 Alert 已补入原型；均提供明确恢复动作、独立 loading、成功反馈并在恢复后移除。周期标签、实际出口、处理状态、右侧处理链和本地运行状态共用同一异常快照，不再出现“失败”和“运行中”并存。当前仍是查询参数驱动的浏览器模拟，正式端接入时必须改读真实运行快照和可重试能力，不能保留模拟定时器。

“当前预设”在现有原型中只是单套演示值，不等同于多轨开启后本周期实际抽中的 1–4 套声音预设及支路详情。后续接入真实运行快照时，单轨继续显示“当前预设”，多轨应改为“当前预设组合”，列出本周期命中的 1–4 套预设标签并提供支路参数详情。

## 已有入口但仍是弱化或模拟状态

- 浏览器原型会校验扩展名、空文件、数量和重复项，并按原子提交语义保持旧池；真实 FFprobe 探测、路径校验和 busy 状态仍由正式桌面端负责。
- PortAudio 卡的位置与字段已按最新设计同步，可在卡内筛选 Host API、选择输出设备、设置 `128–2048 KiB` 内存缓冲并显式应用；原型数据仍是本地模拟，并非正式运行时设备枚举，回退告警也未完整展示。
- 周期卡有结构，但“待媒体边界应用、下一计划、变化次数和进度”仍是模拟数据。
- 授权到期与会话重连的 loading / error / recovery 状态仍未覆盖；媒体引擎、视频、声音与插话的模块内恢复展示已在原型补齐。

## 按用户既定方向刻意省略，不应自动恢复

- 声音与视频联动周期开关。
- 中央顶部的视频处理、普通声音、源规格、最终效果窗口状态条。
- “音视频同时应用”入口；当前原型仅保留独立的声音参数应用。
- 完整实时音频诊断网格；保留波形、出口、状态和当前预设摘要。
- 高级声音抽屉内的 PortAudio 重复配置；设备选择、Host API、缓存设置和原有测试音继续放在主页话术功能上方。
- 固定话术最多 10 条预制的增删改、停止朗读及独立状态；正式端虽已有实现，HTML 原型仍按用户决定留到下个版本。
- 顶部“设置”和“状态”导航；用户已要求取消展示，不应自动恢复。
